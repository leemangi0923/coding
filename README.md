# 제61회 전국기능경기대회 산업용로봇 2·3과제 해설

부산 2·3과제 개정 과제지와 A3 폼지를 기준으로 정리했다.

## 질문 답변 · 3과제 랜덤 배치에서 팩 번호는 어떻게 정하나?

**인덱스 테이블과 A파레트의 팩은 크기와 측정 순서에 따라 로봇이 번호를 부여한다.** 실물 팩에 번호를 기입하라는 요구는 과제지에서 확인되지 않는다. 사각팩과 원형팩을 각각 지정된 구역에 랜덤 배치하고, 프로그램에서 측정 결과로 번호를 정해 HMI에 표시한다. 과제지 4) (8) ①은 HMI에 측정값을 미리 부여할 수 없다고 명시한다.

- **인덱스 테이블(IT)**은 6시 방향 출구에서 측정한다. 출구에 있는 첫 자리부터 시작해 테이블을 반시계 방향으로 한 바퀴 돌리며 각 자리를 같은 작업 위치에서 측정한다.
- **A파레트**는 좌상단 A1부터 우하단 A9까지 **칸 번호 순서**로 측정한다. 이것은 팩을 오름차순으로 깔라는 뜻이 아니다.
- 두 곳 모두 공압 그리퍼를 내려 센서가 켜진 순간의 Z 좌표로 팩 크기를 판별한다. 한계 Z까지 신호가 없으면 빈칸이다. 크기별로 첫 번째와 두 번째 팩에 다음 번호를 붙인다.

| 크기 | A 사각팩 | IT 원형팩 |
| --- | --- | --- |
| 소형 | 1 → 2 | 7 → 8 |
| 중형 | 3 → 4 | 9 → 10 |
| 대형 | 5 → 6 | 11 → 12 |

예를 들어 A1이 중형, A2가 소형, A3이 중형, A4가 중형이면 측정 결과는 순서대로 **3, 1, 4, X**다. 같은 종류·크기의 팩이 세 번째로 나오면 장애물 X다. 장애물은 A 또는 IT 한 곳에만 한 개이며, 검출 즉시 HMI의 C 초기값·목표값에서 미확정 장애물 표기를 사각 또는 원형으로 확정한다.

**오름차순 배치가 적용되는 곳은 측정 후 B파레트다.** 원형팩은 B의 첫째 줄에 7·8·9, 둘째 줄에 10·11·12를 놓는다. 사각팩은 별도 이송에서 첫째 줄에 1·2·3, 둘째 줄에 4·5·6을 놓는다. 해당 묶음에 X가 있으면 3행 3열에 놓는다.

## 2과제 · 3파레트 슬라이드 정렬

A·B·C는 각각 3×3 격자이며, 팩 7개와 빈칸 2개가 있다. 개정본에서는 HMI의 **초기값 복사** 버튼으로 A의 배치를 B와 C 초기값에 입력한다. 세 파레트의 초기 배치는 같고 C 목표값은 별도로 입력한다.

| 파레트 | 목표 배치 |
| --- | --- |
| A | 좌상단부터 행 순서대로 1~7, 마지막 두 칸은 빈칸 |
| B | 좌상단부터 행 순서대로 7~1, 마지막 두 칸은 빈칸 |
| C | HMI에서 받은 별도의 목표 배치 |

팩 하나를 상하좌우로 맞닿은 빈칸에 한 칸씩 옮긴다. 사각팩 1~4는 전기 그리퍼, 원형팩 5~7은 공압 그리퍼를 쓴다. 매 이동 후 실제 배치를 HMI에 반영한다. 기초검사에서는 홈·설정 위치, 그리퍼 자세와 개폐, 부저, BASE 좌표계 XYZ 직선 이동 및 화면 전환을 확인한다.

연습용 탐색에서는 파레트를 길이 9인 배열로 표현하고 두 빈칸을 같은 값으로 둔다. 빈칸에 인접한 팩 하나를 교환해 다음 상태를 만든다. 가능한 배열은 최대 181,440개이므로 기본·랜덤 입력 모두 같은 규칙으로 양방향 너비 우선 탐색을 적용할 수 있다. 이때 최소화하는 값은 이동 횟수다. 실제 주행시간에는 그리퍼 전환과 팩을 잡으러 가는 이동도 포함된다.

## 3과제 · 측정 후 정렬

1. **측정.** 공압 그리퍼로 IT와 A의 팩 크기를 읽고 위 규칙대로 번호와 X를 부여한다. 결과가 나올 때마다 HMI에 표시한다.
2. **원형팩 이송.** 겐트리를 **B-1**에 놓고 전기 그리퍼로 IT의 원형팩을 B에 거치한다. 겐트리를 출구로 이동한 뒤 같은 그리퍼로 C의 초기값 위치에 놓는다.
3. **사각팩 이송.** 겐트리를 **B-2**에 놓고 A의 사각팩도 같은 방법으로 B를 경유해 C 초기값 위치에 둔다. A3 폼지에 표시된 B-1·B-2·출구 위치에서는 각각 B파레트의 파란 선이 기준 위치의 파란 선과 맞아야 한다.
4. **최종 정렬.** 이송이 모두 끝나면 공압 그리퍼로 C를 목표 배치에 맞춘다. C는 4×4 격자로 팩 12개, 빈칸 3개, 고정 장애물 1개가 있다. 팩을 잡고 상하좌우 인접 칸으로 움직일 때 팩이나 장애물을 뛰어넘을 수 없고, 잡은 팩의 하단은 소형 팩 상단보다 낮아야 한다. X는 C 초기값과 목표값에서 같은 자리다.

기초검사에서는 홈·설정, IT 정·역회전, 겐트리 좌·원점·우 이동, PLC 리셋과 HMI 화면 전환을 확인한다. 연습용 정렬 탐색에서는 X가 있는 칸을 이동할 수 없는 칸으로 두고, **C 초기 배치 → C 목표 배치**만 계산한다. 측정 결과에 따른 번호 부여와 B를 거치는 이송은 정렬 탐색 전에 끝나야 한다.
