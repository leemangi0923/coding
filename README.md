# 제61회 전국기능경기대회 산업용로봇 2·3과제 해설

부산 2·3과제 개정 과제지와 A3 폼지를 기준으로 정리했다.
n광주·대구 2과제와 충남·충북 3과제는 [지역별 파레트와 경기 규칙](docs/regional-rules.md)에 정리했다.
n[전체 과제 풀이와 기본 배치 이동 순서](docs/solutions.md)에서 공통 1과제 시뮬레이션과 지역별 정렬 알고리즘을 실행할 수 있다.

## 파레트 규격과 배치

| 과제 | 구역 | 격자·자리 수 | 폼지 격자 외곽 참고치 | 시작 상태와 역할 |
| --- | --- | --- | --- | --- |
| 2 | A | 3행 × 3열, 9칸 | 약 120 × 120 mm | 팩 7개 + 빈칸 2개. 오름차순으로 정렬 |
| 2 | B | 3행 × 3열, 9칸 | 약 120 × 120 mm | A와 같은 초기 배치. 내림차순으로 정렬 |
| 2 | C | 3행 × 3열, 9칸 | 약 120 × 120 mm | A와 같은 초기 배치. HMI에서 별도 입력한 목표로 정렬 |
| 3 | A | 3행 × 3열, 9칸 | 약 120 × 120 mm | 사각팩 6개를 측정. X가 A에 있으면 빈칸 2개, IT에 있으면 빈칸 3개 |
| 3 | IT | 원주에 8자리 | A3 격자 치수 적용 대상 아님 | 원형팩 6개를 측정. X가 IT에 있으면 빈자리 1개, A에 있으면 빈자리 2개 |
| 3 | B | 3행 × 3열, 9칸 | 약 120 × 120 mm, 파란 표식 띠 별도 | 처음에는 비어 있음. 한 번에 정상 팩 6개, 해당 묶음에 X가 있으면 7개 이송 |
| 3 | C | 4행 × 4열, 16칸 | 약 160 × 160 mm | 처음에는 비어 있음. 이송 후 정상 팩 12개 + 고정 X 1개 + 빈칸 3개 |

- A3 폼지의 외곽 참고치는 원본 미리보기의 A3 가로 용지(420 × 297 mm) 비율로 추정했다. 인접 칸의 중심 간격은 행·열 모두 약 40 mm다. 공식 과제지에 격자 실측 치수나 공차가 따로 적혀 있지 않아 실제 좌표는 지급 폼지에서 확인한다.
- 두 과제의 기구 배치도는 1200 × 900 mm 범위를 표시한다. 구역과 방향을 지키고 채점 가능한 범위 안에서 구조물과 폼지를 배치한다. 경기에서 폼지를 사용하는 경우 당일 제공된 폼지만 사용한다.
- 2과제 폼지에는 3×3 격자가 세 개 있다. 3과제 폼지에는 A·B용 3×3 격자, C용 4×4 격자, B-1·B-2·출구 표식이 있다. B-1과 B-2는 같은 B파레트가 이동하는 두 거치 위치다.
- 격자 번호는 좌상단부터 행 순서로 읽는다. 3×3의 9번은 우하단이고, 4×4의 우하단은 16번이다. 인덱스 테이블은 격자가 아니라 6시 출구를 기준으로 별도 관리한다.
- 공통 지급 목록의 사각팩 단면은 20 × 20 mm, 원형팩 지름은 20 mm다. 높이는 소형 40 mm, 중형 50 mm, 대형 60 mm다. 폼지의 적색 원·사각형이 팩 아래로 보이는지 채점에서 확인하므로 중심에 놓는다.

## 질문 답변 · 3과제 랜덤 배치에서 팩 번호는 어떻게 정하나?

**인덱스 테이블과 A파레트의 팩은 크기와 측정 순서에 따라 로봇이 번호를 부여한다.** 실물 팩에 번호를 기입하라는 요구는 과제지에서 확인되지 않는다. 사각팩과 원형팩을 각각 지정된 구역에 랜덤 배치하고, 프로그램에서 측정 결과로 번호를 정해 HMI에 표시한다. 과제지 4) (8) ①은 HMI에 측정값을 미리 부여할 수 없다고 명시한다.

- **인덱스 테이블(IT)**은 6시 방향 출구에서 측정한다. 출구에 있는 첫 자리부터 시작해 테이블을 반시계 방향으로 한 바퀴 돌리며 각 자리를 같은 작업 위치에서 측정한다.
- **A파레트**는 좌상단 A1부터 우하단 A9까지 **칸 번호 순서**로 측정한다. 팩의 배치는 랜덤이며 읽는 순서는 고정이다.
- 두 곳 모두 공압 그리퍼를 내려 센서가 켜진 순간의 Z 좌표로 팩 크기를 판별한다. 한계 Z까지 신호가 없으면 빈칸이다. 크기별로 첫 번째와 두 번째 팩에 다음 번호를 붙인다.

| 크기 | A 사각팩 | IT 원형팩 |
| --- | --- | --- |
| 소형 | 1 → 2 | 7 → 8 |
| 중형 | 3 → 4 | 9 → 10 |
| 대형 | 5 → 6 | 11 → 12 |

예를 들어 A1이 중형, A2가 소형, A3이 중형, A4가 중형이면 측정 결과는 순서대로 **3, 1, 4, X**다. 같은 종류·크기의 팩이 세 번째로 나오면 장애물 X다. 장애물은 A 또는 IT 한 곳에만 한 개이며, 검출 즉시 HMI의 C 초기값·목표값에서 미확정 장애물 표기를 사각 또는 원형으로 확정한다.

**오름차순 배치가 적용되는 곳은 측정 후 B파레트다.** 원형팩은 B의 첫째 줄에 7·8·9, 둘째 줄에 10·11·12를 놓는다. 사각팩은 별도 이송에서 첫째 줄에 1·2·3, 둘째 줄에 4·5·6을 놓는다. 해당 묶음에 X가 있으면 3행 3열에 놓는다.

## 2과제 · 3파레트 슬라이드 정렬

A·B·C는 각각 3×3 격자이며, 팩 7개와 빈칸 2개가 있다. 개정본에서는 HMI의 **초기값 복사** 버튼으로 A의 배치를 B와 C 초기값에 입력한다. 세 파레트의 초기 배치는 같고 C 목표값은 별도로 입력한다.

| 파레트 | 목표 배치 |
| --- | --- |
| A | 좌상단부터 행 순서대로 1~7, 마지막 두 칸은 빈칸 |
| B | 좌상단부터 행 순서대로 7~1, 마지막 두 칸은 빈칸 |
| C | HMI에서 받은 별도의 목표 배치 |

| 팩 종류 | 소형 | 중형 | 대형 | 그리퍼 |
| --- | --- | --- | --- | --- |
| 사각 | 1 | 2 | 3, 4 | 전기 |
| 원형 | 5 | 6 | 7 | 공압 |

팩 하나를 같은 파레트에서 상하좌우로 맞닿은 빈칸에 한 칸씩 옮긴다. 대각선, 여러 칸을 건너뛰는 이동, 다른 팩 위를 넘는 이동은 금지다. 사각팩 1~4는 전기 그리퍼, 원형팩 5~7은 공압 그리퍼를 쓴다. 매 이동 후 실제 배치를 HMI에 반영한다. HMI에서 A·B와 C의 현재 배치를 표시하고 C 목표값을 유지한다.

### 2과제 기초검사

| 항목 | 요구 동작 |
| --- | --- |
| 홈·설정 | 홈 `posj(0,0,0,0,0,0)`, 설정 `posj(90,0,90,0,0,0)`. 관절 속도·가속도 20~50 |
| 그리퍼 자세 | 선택한 그리퍼가 아래를 향하도록 `posj(90,0,90,a,b,c)`로 이동. 마지막 세 각은 선수 설정 |
| 출력 | 전기·공압 그리퍼와 부저 각각 ON/OFF |
| XYZ 조그 | BASE 기준 X·Y·Z의 +/− 버튼을 누르는 동안 해당 방향으로 직선 이동. 선속도·가속도 50~200, 축 방향 기울기 오차 ±5° |
| 화면·종료 | 동작검사로 전환, 기본값과 초기값 복사로 기본 입력 화면 구성, 기초검사로 복귀. 종료 버튼을 누르면 흰색 LED가 점멸에서 점등으로 전환 |

### 2과제 알고리즘 연습

연습용 탐색에서는 파레트를 길이 9인 배열로 표현하고 두 빈칸을 같은 값으로 둔다. 빈칸에 인접한 팩 하나를 교환해 다음 상태를 만든다. 가능한 배열은 최대 181,440개이므로 기본·랜덤 입력 모두 같은 규칙으로 양방향 너비 우선 탐색을 적용할 수 있다. 이때 최소화하는 값은 이동 횟수다. 실제 주행시간에는 그리퍼 전환과 팩을 잡으러 가는 이동도 포함된다.

## 3과제 · 측정 후 정렬

1. **측정.** 공압 그리퍼로 IT와 A의 팩 크기를 읽고 위 규칙대로 번호와 X를 부여한다. 결과가 나올 때마다 HMI에 표시한다.
2. **원형팩 이송.** 겐트리를 **B-1**에 놓고 전기 그리퍼로 IT의 원형팩을 B에 거치한다. 겐트리를 출구로 이동한 뒤 같은 그리퍼로 C의 초기값 위치에 놓는다.
3. **사각팩 이송.** 겐트리를 **B-2**에 놓고 A의 사각팩도 같은 방법으로 B를 경유해 C 초기값 위치에 둔다. A3 폼지에 표시된 B-1·B-2·출구 위치에서는 각각 B파레트의 파란 선이 기준 위치의 파란 선과 맞아야 한다.
4. **최종 정렬.** 이송이 모두 끝나면 공압 그리퍼로 C를 목표 배치에 맞춘다. C는 4×4 격자로 팩 12개, 빈칸 3개, 고정 장애물 1개가 있다. 팩을 잡고 상하좌우 인접 칸으로 움직일 때 팩이나 장애물을 뛰어넘을 수 없고, 잡은 팩의 하단은 소형 팩 상단보다 낮아야 한다. X는 C 초기값과 목표값에서 같은 자리다.

### 3과제 기초검사

| 항목 | 요구 동작 |
| --- | --- |
| 홈·설정 | 홈 `posj(90,0,90,90,90,0)`. 설정은 IT 6시 출구 상단으로 이동하고 팩이 놓여 있으면 그 위로 간다. 관절 속도·가속도 20~50 |
| 인덱스 테이블 | HMI 6시 위치에 빨간 사각팩을 표시하고 실물 출구에 소형 사각팩을 둔다. 한 자리 자연수를 입력해 그 수만큼 정회전은 시계 방향, 역회전은 반시계 방향으로 이동 |
| 겐트리 | 좌·원점·우 버튼이 실제 장치를 해당 위치로 이동 |
| PLC 리셋 | IT와 겐트리 모두 센서 기준으로 원점 복귀. HMI의 IT 상태도 초기화하고 겐트리 원점에 빨간 선 표시 |
| 화면·종료 | 동작검사 전환, 기본값 화면, 기초검사 복귀. 종료 버튼을 누르면 흰색 LED가 점멸에서 점등으로 전환 |

### 3과제 HMI와 알고리즘 연습

HMI의 IT와 A는 측정 결과로 채우고 B는 거치·반출 상태를 반영한다. C는 HMI에서 받은 초기값과 목표값을 사용한다. 이송과 정렬에 맞춰 C의 현재 팩 배치를 표시한다.

연습용 정렬 탐색에서는 X가 있는 칸을 이동할 수 없는 칸으로 두고, **C 초기 배치 → C 목표 배치**만 계산한다. 측정 결과에 따른 번호 부여와 B를 거치는 이송은 정렬 탐색 전에 끝나야 한다.

## 공통 진행과 평가 규칙

1. 사전 준비에서 지급품과 로봇·PLC·HMI 통신을 확인한다. 지정 자리와 공식 로봇을 사용하고 장비 개조나 임의 부품 교체는 금지다.
2. MCB를 켜고 SS를 자동(A)에 둔 뒤 PB1을 눌러 PLC에 전원을 공급한다. 평가 전 공압과 로봇의 흰색 점등 자동 상태를 확인한다.
3. 과제별 수행 시간은 3시간이다. 평가 순서는 **기초 → 기본동작 → 랜덤동작**이다. 기초검사는 항목마다 프로그램 실행이 가능하며 평가 중 유지보수는 금지다.
4. 기본동작은 과제지의 기본 배치와 HMI를 일치시킨다. 랜덤동작은 심사위원이 제시한 배치·입력값을 사용한다. 준비 시간은 각각 5분·7분이며 이 시간에는 프로그램·하드웨어 유지보수가 가능하다. 평가 시간은 각각 10분·15분이며 Start 버튼만 누를 수 있다.
5. HMI의 로봇 상태는 **준비 → 주행 → 완료**로 바뀐다. 다음 동작 전까지 해당 작업 결과를 화면에 갱신한다. 시작 및 종료에서 부저를 각각 0.5초간 울린다. 마지막 이동 후 로봇을 정지한 뒤 종료 부저를 울린다. 부저 동작을 포함한 주행시간을 소수점 이하 버림으로 계산해 완료 표시 후 정수 초로 표시한다.
6. 시간 초과 시 심사위원은 동작을 중지시키고 실제 수행 부분까지 채점할 수 있다. 기본·랜덤 평가 중 프로그램 비정상 종료 또는 로봇 전원 차단으로 정지한 경우 재평가 1회를 제공한다. HMI 시간과 심사위원의 측정값 차이가 크고 코드에 문제가 있으면 시간 순위 점수를 받을 수 없다.
7. 지정되지 않은 물품 반입, 미승인 메모리, 봉인 USB 임의 개봉, 휴대전화 소지, 지급 PC로 인터넷 접속, 경기 중 외부와 경기 정보 교환에 관한 과제지 규정을 따른다. 채점 시 IDLE 사용이 금지되고, 경기 종료 후 지급 컴퓨터는 지정 장소에 제출한다. 당일 추첨으로 변경된 사항은 현장에서 배부하는 과제지를 기준으로 한다.

### 배점과 감점

| 구분 | 2과제 | 3과제 |
| --- | --- | --- |
| 기초검사 | 16점 | 18점 |
| 기본동작검사 | 7점 | 8.4점 |
| 랜덤동작검사 | 7점 | 8.5점 |
| 시간 기본점수 | 기본·랜덤 합계 7점 이상이면 4.9점에서 감점 적용 | 개정본은 별도 시간 기본점수 없이 감점 적용 |
| 시간 순위 | 기본·랜덤 합계 14점일 때 최대 0.1점 | 기본·랜덤 합계 16.9점일 때 최대 0.1점 |

- 2과제의 기본·랜덤은 각각 초기 배치 1점, A 정렬 1점, B 정렬 1점, C 정렬 1.5점, 실시간 표시 1.5점, 완료 및 주행시간 기록 1점이다. 실시간 표시는 파레트별 0.5점이며 해당 파레트 정렬이 올바르게 끝나야 부여한다.
- 3과제 개정 동작확인서 기준으로 초기 배치 1점, 측정·번호 1.4점, B 경유 이송 1.3점, C 정렬 2점, 실시간 표시 1.5점이다. 완료 및 주행시간은 기본 1.2점, 랜덤 1.3점이다. 실시간 표시 배점은 IT·A·C에 각 0.5점이며 해당 단계를 올바르게 마쳐야 한다. 개정본의 일부 본문 수치와 배점 표기가 달라 실제 평가에는 현장 확정 채점표를 적용한다.
- 공통 감점 항목은 실행 후 HMI 초기값을 수정해 재평가하는 경우(최대 2회), 시작 또는 종료 부저 누락(최대 1회), 팩을 놓은 뒤 대응하는 적색 원 또는 사각형이 보이는 경우(해당 팩 수)다. 개소당 0.1점이다.
