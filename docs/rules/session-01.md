폼지 치수는 HWP·HWPX 도면에서 100% 배율로 환산한 참고치다. 행×열은 HMI가 보는 방향을 기준으로 쓰며, 종이에 인쇄된 방향은 다를 수 있다. 경기에서는 당일 지급 폼지와 과제지의 구역·방향을 따른다. 네 과제의 기구 배치도에 표시된 작업대 범위는 1200×900 mm다.

## 경기 2과제 · 작업 이력 관리 시스템

### 파레트와 초기·목표 배치

| 파레트 | 구조·폼지 | 팩과 배치 |
| --- | --- | --- |
| A | 평면 4행×4열, 약 150×150 mm, 피치 약 37.5 mm | 소형 사각 1~4, 중형 사각 5~7, 대형 사각 X 1개로 총 8개. 숫자·문자는 사각팩 상단면에 붙인다. X는 모서리를 뺀 녹색 2번 구역에서 한 칸, H는 1번 구역에서 한 칸을 HMI에만 지정한다. 팩은 한 칸에 한 개다. |
| B | 바닥 5자리, 높이 방향 최대 3층. 인쇄 폼지는 40×200 mm의 5칸 띠, 칸 피치 약 40 mm | 대형 원형 A, 중형 원형 B~D, 소형 원형 E~I로 총 9개. 문자는 팩 옆면에 붙이고 정면에서 읽을 수 있게 쌓는다. |

기본검사는 과제지의 초기·정렬 그림을 사용한다. 랜덤검사는 심사위원이 제시한 초기·목표를 HMI에 반영한다. A의 기본 예시는 X와 H가 각각 2행 1열과 2행 2열에 고정되고, 숫자팩 1~7이 이동한다. B의 기본 목표는 정면 왼쪽부터 아래→위로 `[E]`, `[F,B]`, `[G,C,A]`, `[H,D]`, `[I]`다. 여기서 B의 `H`는 원형팩 문자이고, A의 `H`는 홀이다.

### 그리퍼와 이동 제한

- **A**는 소형 사각을 전기, 중형 사각을 공압 그리퍼로 이동한다. 잡은 팩은 상하좌우로만 움직이며 하단을 40 mm보다 낮게 유지한다. 다른 팩 위를 넘어갈 수 없고 X는 고정이다. H는 팩을 든 채 통과할 수 있으며 내려놓을 수 없다.
- **B**는 공압 그리퍼만 사용해 3차원 기준 상하좌우로 움직인다. 팩을 잡은 채 파레트 밖으로 나갈 수 없고 적층은 최대 3층이다.

### HMI와 이력

- A는 위에서 본 모습, B는 정면 모습으로 표시한다. 초기·완료 배치 및 정렬 중 현재 상태를 보여준다.
- 팩 이동 이력에는 **이동 순서, 파레트, 팩 종류, 숫자·문자, 출발 위치, 도착 위치**를 기록한다. 순서는 1부터 부여한다. 위치값은 과제지의 이력용 번호도를 따른다.
- 이력은 한 화면에 3개씩 표시한다. 새 행은 추가 즉시 보이고 스크롤로 앞뒤 이력을 조회한다. 저장된 이력이 3개 이상이면 빈 행을 표시하지 않는다. 기록 수에는 상한이 없다.
- 한 번에 한 행을 선택하며 선택 색상은 노란색이다. 같은 행을 다시 누르면 해제되고, 다른 행을 누르면 선택이 바뀐다. 스크롤해도 선택은 유지된다.
- **선택삭제** 뒤에는 아래 행이 빈자리를 채운다. **전체삭제**는 모든 행을 지운다. **되돌리기**는 가장 최근 삭제를 복구하며 선택삭제와 전체삭제를 모두 지원하고 횟수 제한이 없다. 전체삭제를 복구하면 1번 이력부터 표시한다.
- 과제지 이력 번호도에서 A의 자리 표기는 `1~8, 10~17`로 9를 건너뛴다. 번호도와 예시 화면의 표기를 대조할 때는 이 차이를 확인한다.

### 채점

기초 16점, 기본 7점, 랜덤 7점이다. 기본·랜덤 각각 초기 배치 1점, A·B 정렬 각 1점, A·B 실시간 표시 각 0.5점, 완료·주행시간 1점, 이력 기능 2점이다. 이력은 **최소 10개**가 있어야 채점하며 스크롤·전체삭제·선택삭제·되돌리기 각 0.5점이다. 채점할 때는 오름차순 조회, 전체삭제 후 복구, 선택삭제 후 복구를 확인하고 마지막에 원래 이력과 대조한다.

## 경기 3과제 · 배송 과정

### 파레트와 초기·목표 배치

| 구역 | 구조·폼지 | 시작 상태와 역할 |
| --- | --- | --- |
| A·B | 각각 4행×3열 12칸 기준, 단독 폼지 격자 약 120×160 mm | A에 사각팩을 랜덤 배치한다. B에는 IT를 거쳐 **A의 초기 배치와 같은 칸**에 팩을 놓는다. |
| IT | 원주형 8자리, 동작검사 투입 9시·반출 3시 | 임시 적재·이송. 적재 중인 팩의 설정 무게 합계를 표시한다. |
| C | 4행×6열, 두 격자를 이은 폼지 도형 약 225×150 mm | 가동 원형팩과 고정 X가 있는 경로 구역. 도면 윗줄부터 왼쪽 끝은 입구 후보 1~4, 오른쪽 끝은 출구 후보 5~8이다. |
| D1~D4·GR | D는 한 자리씩이며 대기 자리까지 일렬. 폼지의 정렬 띠 도형 약 200×50 mm, 겐트리 선 표식 도형 약 120×120 mm | HMI에서 지정한 무게의 팩을 각 D 자리로 배달한다. 겐트리는 한 번에 한 팩을 운반한다. |

소형 사각 **10~29 kg**, 중형 **30~49 kg**, 대형 **50~60 kg** 범위에서 심사위원이 크기별 무게를 추첨한다. 이는 과제의 표시·판정용 값이다. 사각팩은 크기별 1~6개, 총 11개 이내다. C 구성표에는 중형 원형 X 2개와 대형 원형 6개, 총 8개가 기재돼 있다. D1~D4의 목표 무게는 심사위원이 추첨한다. 기본 HMI 예시의 크기별 설정값은 15·34·56 kg, IT 한도는 120 kg이다.

### 그리퍼와 이동 제한

1. **A → IT → B.** 전기 그리퍼로 A의 팩을 IT 9시 입구에 놓고 3시 출구에서 꺼내 B에 배치한다. 이 구간에서 로봇의 이동 방향 제한은 없고 IT는 정·역회전 모두 사용할 수 있다. 적재 합계는 IT 최대 무게를 넘으면 안 된다. 최대 무게 범위는 60~200 kg이며 심사위원이 정한다.
2. **C의 빈 경로 만들기.** HMI에서 입구 한 곳과 서로 다른 두 출구를 지정한다. 입구·출구에는 X를 놓을 수 없고 X로 도착지를 막을 수 없다. X는 이동할 수 없다. 초기부터 빈 경로가 있어도 팩을 최소 두 번 이동·배치한다. 이동은 상하좌우이며, C의 **원형팩**을 상하로 이동할 때는 전기, 좌우로 이동할 때는 공압을 사용한다. 잡은 팩의 하단은 40 mm보다 낮게 유지한다.
3. **B → C → GR → D.** 배달 팩의 무게가 **40 kg 이하**면 청색 출구, **40 kg 초과**면 적색 출구다. C 경로를 만든 뒤 겐트리는 대기 라인에 있어야 한다. 출구에서 겐트리에 팩을 한 개만 놓고, 목적 D의 폼지 선과 겐트리 선을 일치시킨 뒤 전기 그리퍼로 배치한다.

### HMI와 장치

- HMI에는 IT 최대·현재 무게, 소·중·대 설정 무게, C의 입구·색상별 출구, D1~D4 목표 무게와 현재 배치를 표시한다. A·B·C·D 및 IT의 현재 정보는 실시간으로 갱신한다.
- **기초검사에서 IT 예시 출구는 6시**, 배송 동작검사에서 **IT 반출 위치는 3시**다.
- 동작 조건 (9)는 C의 원형팩 이동에만 방향별 그리퍼를 지정한다. 경로를 지나는 **배달용 사각팩**의 C 구간 그리퍼는 해당 항에 따로 적혀 있지 않다.
- 과제 개요는 A의 사각팩 최대 11개를 설명하고, 기본 완료화면은 D1~D4 네 자리의 배송 후 B에 팩이 남아 있는 모습을 보여준다. C 통과 채점도 경로 0.2점과 팩당 0.2점, 총 1점이다. 랜덤 검사에서 배달할 팩 수와 나머지 팩 처리는 D 목표와 현장 지시로 확인한다.

### 채점

기초 16점, 기본 7점, 랜덤 7점이다. 기본·랜덤 각각 초기 배치 1점, A→IT→B 1점(배치 0.5, 무게 제한 0.5), C 경로·통과 1점(경로 0.2, 각 팩 0.2), 겐트리 적재·D 배치 1.5점(0.5+1), 실시간 표시 1.5점(IT 및 A~D 각 0.3), 완료·주행시간 1점이다. 실시간 표시 점수는 해당 구역의 정렬 완료를 전제로 한다.

## 경남 2과제 · 2차정렬-1

### 파레트와 초기·목표 배치

| 구역 | 구조·치수 | 팩과 목표 |
| --- | --- | --- |
| A1·A2 | 각 3칸 길이의 띠, 도면 120×40 mm. 양끝 두 자리에 팩 중심 표식, 가운데는 빈 칸. 적층 최대 3층 | 소형 사각 1~5 총 5개. A1 목표는 HMI 제시값이며 A2 목표는 A1 목표의 **좌우 반전**이다. |
| B1·B2 | 각 2행×4열, 도면 160×80 mm. B1의 두 2×2 구역이 b1·b2 | 중형 사각 1~4, 중형 원형 1~4 총 8개. B1 목표에서 b1은 사각만, b2는 원형만 놓는다. B2 목표는 B1 목표를 **상하·좌우 모두 반전**한 상태다. |
| C | 4행×4열, 도면 160×160 mm | 대형 사각 1~4, 원형 1~4 총 8개. 초기→임시→목표 세 배치가 있다. 목표에서 원형팩을 대형 사각팩에 올릴 경우 사각팩의 숫자가 보여야 한다. |

전체 21개는 A 5개, B 8개, C 8개다. A2·B2는 같은 팩을 이어받는다. 폼지 도형의 중심 피치는 약 40 mm다. 파일명은 A3용이지만 문서 자체 용지 설정은 A4 가로에 해당한다. 인쇄할 때 표시 크기를 실물 도면과 대조한다.

### 그리퍼와 이동 제한

- **전체 순서**는 **A1 → B1 → B2 → A2 → C**다.
- **A1·A2**의 정렬에는 전기·공압 모두 사용할 수 있다. A1에서 A2로 옮기는 과정에서는 팩 5개를 먼저 모두 B1에 옮긴 뒤 A2로 이동한다. B1으로 옮길 때 1~3번은 전기, 4~5번은 공압이다.
- **B1**은 사각=전기, 원형=공압이다. **B2**는 사각=공압, 원형=전기다. 정렬은 상하좌우로 인접한 두 팩을 서로 교환하는 방식이다.
- **C**는 사각=공압, 원형=전기다. 두 그리퍼로 동시에 잡을 수 없다. 상하좌우 이동만 허용하고 대각선은 금지다. 다른 팩은 넘지 못하지만 원형팩은 사각팩을 넘을 수 있다. 사각팩을 들고 이동할 때 하단을 눕힌 팩의 높이보다 낮게 맞춘다.
- C의 팩을 임시맵으로 옮긴 뒤 `posj(0,0,90,90,0,0)`에서 **5초간 정지**해 임시맵을 확인시킨다. 임시맵→목표 단계에서는 **모든 팩을 팩당 한 번씩** 옮긴다.

### HMI와 확인 사항

- 기본 입력은 기본값 버튼 또는 HMI에서 설정한다. 랜덤 배치는 심사위원의 값을 입력한다. A1·A2는 적층을 정면에서 표현하고 B1·B2·C는 격자로 보여준다. 입력 화면의 A2·B2 항목은 초기맵으로 표시되므로 2차 정렬 목표와 구분해 읽는다.
- **C 원형팩 크기 표기가 다르다.** 개요 (7)에는 소형 원형으로 적혀 있고, 종류표는 1~4를 대형 원형 열에 둔다. 이 문서에서는 번호·개수와 이동 조건을 공통으로 정리했다. 크기는 당일 배부 과제지에서 확인한다.
- 동작 순서는 A1→B1→B2→A2이고 A 팩은 B1을 경유한다. B1을 경유지로 쓸 때의 거치 시점과 거치 위치는 과제지에 세부 지정이 없어 현장 설명을 확인한다.

### 채점

기초 16점, 기본 7점, 랜덤 7점이다. 기본·랜덤 각각 초기 배치 1점, A 1점, B 1점, C 1.5점, 실시간 표시 1.5점(A·B·C 각 0.5, 해당 파레트 정렬 완료 시), 완료·주행시간 1점이다. 완료·주행시간 배점은 정렬·실시간 표시 항목에서 일부라도 점수를 받은 경우 적용한다.

## 경남 3과제 · 2차정렬-2

### 파레트와 초기·목표 배치

A1·A2, B1·B2, C의 구조와 반전 조건은 [경남 2과제](#경남-2과제--2차정렬-1)와 같다. 3과제 종류표와 개요는 C 원형 1~4를 **소형**으로 표기한다. A 5개, B 8개, C 8개에 IT 표시용 원형 5개를 더해 총 **26개**다. IT 표시용은 종류표 기준 소형 1~3, 중형 4~5다. 겐트리 폼지는 200×40 mm의 5칸 띠이며 소·중·대 표식은 첫째·셋째·다섯째 칸에 있다. A·B·C 폼지와 마찬가지로 파일명은 A3용이고 문서 용지 설정은 A4 가로에 해당한다.

### 그리퍼와 이동 제한

- **전체 순서**는 **C → A1 → B1 → B2 → A2**다. A의 B1 경유, 전기·공압 구분, B의 인접 교환과 그리퍼 전환, C의 이동 제한·임시맵·5초 정지·팩당 한 번 이동 규칙을 적용한다.
- **A와 C에서 팩을 옮기는 동안** IT에는 들고 있는 팩의 **번호**를, 겐트리에는 팩의 **크기**를 표시한다. A 조건에는 IT의 표시 위치가 6시 방향으로 명시돼 있다. C에서의 번호 표시는 동작 조건 (9) ⑦을 따른다.
- 마지막 팩을 옮긴 뒤 **IT와 겐트리를 원점으로 복귀**시킨 다음 로봇을 정지하고 종료 부저를 울린다.

### HMI와 장치

A1·A2, B1·B2, C의 배치와 IT·겐트리 상태를 실시간으로 나타낸다. 기초검사의 PLC 리셋과 과제를 마칠 때의 장치 원점 복귀를 각각 확인한다. 기본·랜덤 초기값, 임시맵 확인 절차와 A2·B2 초기맵/목표의 구분은 2과제와 같다.

### 채점

기초 16점, 기본 7점, 랜덤 7점이며 단계별 배점은 경남 2과제와 같다. 실시간 항목은 총 1.5점으로 명시하며 문구는 **IT·겐트리·A·B·C 정보를 확인하고 파레트당 0.5점**이라고 적는다. 따라서 표시 장치도 확인 대상에 포함되며 A·B·C의 합계가 1.5점이라는 구조다.
