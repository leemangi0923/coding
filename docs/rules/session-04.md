네 과제의 기구 배치도는 작업대 **1200×900 mm**를 기준으로 한다. 폼지는 모두 A3 가로 설정이다. 아래 치수는 원본 도형을 100% 배율로 환산한 폭×높이 참고치다. 실기에서는 당일 지급 폼지를 과제지의 지정 구역과 방향에 놓는다. 공통 지급 목록 기준 사각팩 단면은 20×20 mm, 원형 지름은 20 mm, 소·중·대 높이는 각각 40·50·60 mm다.

## 충남 2과제 · 블록 분류

### 파레트와 팩

| 구역 | 폼지 구조·치수 | 팩 구성 |
| --- | --- | --- |
| A | 5행×5열 범위의 20자리, 약 200×200 mm, 중심 간격 40 mm. 모서리 2×2 구역 A1~A4와 연결 통로 | 소형 사각 6개(○·◇ 각 3개), 소형 원형 6개(□·△ 각 3개) |
| B | 가로 7개 중심 표식, 약 280×40 mm, 중심 간격 40 mm. HMI는 옆에서 본 2층 배치를 표시 | 눕힌 대형 사각 A·B·C, 대형 원형 1~4 |
| C | 3행×6열, 약 290×140 mm, 중심 간격 50 mm. 둘째 행 3·4열은 H | 중형 사각 1~6, 대형 사각 7~9, 중형 원형 10~15 |

실물은 총 34개다. A·C 표식은 상단, B 표식은 옆면에 붙인다. B에서 초기 2층에 눕힌 사각팩을 올리면 두 받침은 모두 사각이거나 모두 원형이어야 한다. 이 받침 조합은 **초기 배치 조건**이다. C의 랜덤 초기값에서 2층 팩을 놓으려면 같은 자리 1층에 팩이 있어야 한다.

### 이동과 HMI

- 파레트의 정렬 순서는 자유다. 한 번에 팩 한 개만 잡고 해당 파레트 안에서만 옮긴다.
- **A**는 HMI의 A1~A4에 ○·△·□·◇를 중복 없이 하나씩 지정하고 같은 표식끼리 해당 모서리 구역으로 분류한다. 완료 시 연결 통로에는 팩이 없어야 한다. 상하좌우로 이동하고 하단을 소형팩 상단보다 낮게 유지한다. 그리퍼는 표식과 관계없이 **실물 사각은 전기, 원형은 공압**이다.
- **B**는 사각에 **공압**, 원형에 **전기**를 사용한다. 동시에 두 팩을 잡을 수 없고 정렬 중 최대 2층이다. 로봇이 있는 쪽을 왼쪽으로 보고 HMI 목표의 옆면 배치에 맞춘다.
- **C**는 사각에 전기, 원형에 공압을 사용한다. 상하좌우로만 움직이고 팩 하단은 **바닥에서 120 mm 미만**으로 유지한다. H는 통과할 수 있고 내려놓을 수 없다. 1·2층을 HMI 목표에 맞춘다.
- A의 분류 표식과 B·C 목표를 HMI로 확인하고 세 파레트의 현재 배치를 실시간으로 갱신한다. C는 층별 화면 두 개를 쓴다. 과제지 일부 그림의 B1·B2 표기는 3×6 C 화면에 붙어 있다.

## 충남 3과제 · 블록 분류

### 파레트와 팩

A·B·C의 형태와 인쇄 치수, H 두 자리, 팩 수(12·7·15개)는 [충남 2과제](#충남-2과제--블록-분류)와 같다. 3과제 폼지에는 적색 선이 있는 약 120×120 mm 겐트리 표식 도형도 있다. 인덱스테이블(IT)에 대형 사각·원형 표시 팩을 하나씩 더해 실물은 총 36개다. A·C와 IT는 팩 상단에, B는 옆면에 표시한다. 기구 배치도에 나온 IT·겐트리·파레트 위치를 고정한다.

**C의 9번은 자료 안에서 모양이 다르게 표시된다.** 3과제 종류표는 중형 사각 1~6, 대형 사각 7·8, 중형 원형 9~14, 대형 원형 15로 구분한다. 기본 HMI 그림은 사각 1~9와 원형 10~15로 표시한다. 9번의 실물 모양은 당일 확정 과제지에서 확인한다.

### 동작 조건

- **모든 집기 전 IT 확인.** 동작검사 시작 시 로봇 테이블 정면 기준 12시(원문의 0시)에 ‘사각’ 표시 팩, 6시에 ‘원형’ 표시 팩을 둔다. A·B·C에서 팩을 집을 때마다 **실물 모양과 같은 표시 팩을 먼저 IT 6시 출구에 위치**시킨다. 한 번에 한 팩만 잡고 해당 파레트를 벗어나지 않는다. 정렬 순서는 자유다.
- **A**는 A1~A4에 HMI가 지정한 네 표식별로 분류한다. 상하좌우 이동, 사각 전기·원형 공압, 하단은 소형팩 상단 미만이며 완료 시 연결 통로를 비운다.
- **B**는 사각 공압·원형 전기로 최대 2층까지 정렬한다. 로봇 쪽을 왼쪽으로 본다. **팩을 집기 전과 놓기 전** 겐트리의 빨간 선을 해당 위치에 맞춘다. 눕힌 팩은 차지하는 두 자리 중 한 곳에 맞춘다. 초기 2층의 눕힌 사각에는 같은 모양의 두 받침을 사용한다.
- **C**는 초기 2층 아래에 1층 받침을 둔다. 이동은 상하좌우, 사각 전기·원형 공압이며 하단을 중형 두 개 높이인 **100 mm 미만**으로 유지한다. H는 통과만 할 수 있다. HMI 목표에 1·2층을 맞춘다.
- HMI에는 A·B·C의 작업 상태를 실시간으로 반영한다. IT 모양 표시 0.3점은 세 파레트를 모두 정렬하고 모든 집기에서 IT 조건을 지켰을 때 부여한다.

## 충북 2과제 · 불빛 정렬

### 파레트와 팩

| 구역 | 폼지 구조·치수 | 팩 구성 |
| --- | --- | --- |
| A | 5행×5열, 약 200×200 mm | 소형 사각 1~4, 중형 사각 5, 대형 원형 전등팩 1개 |
| B | 5열×4행 범위, 폼지 약 200×160 mm, 중심 표식 11개. 과제지 그림의 중앙 초록 구역과 바깥 세 자리를 구분 | 사각 소형 1·2, 중형 3·4, 대형 5·6. 원형 소형 7·8, 중형 9·10, 대형 11·12. 대형 눕힌팩 2개 |
| C | 4행×4열 범위, 약 160×160 mm, 번호팩 자리와 노란 불빛팩 자리 | 소형 사각 1·2, 대형 사각 3, 소형 원형 4·5, 중형 원형 6~8, 대형 원형 9 |
| D | 기구 배치도상의 불빛팩 거치 위치 | 소형 원형 불빛팩 1개. A와 C에서 사용 |

폼지 중심 간격은 약 40 mm다. 총 실물은 30개다. 전등팩, 눕힌팩, 불빛팩처럼 종류표에서 0으로 표시된 팩은 실물에 숫자를 붙이지 않는다. 과제지 표기 그림에서 A·C는 상단을, B는 상단과 옆면을 보여준다. D와 불빛팩은 HMI에 표시하지 않는다.

### A · 전등팩, 불빛팩과 암흑 구역

- 초기에는 전등팩의 상하좌우를 비우고 1~5번을 일렬로 놓지 않는다. HMI 목표에서 전등팩은 중앙이고 상하좌우 네 칸을 전부 막는 배치는 불가하다.
- 전등팩은 상하좌우에 팩이 없을 때 옮길 수 있다. 번호팩 1~5는 집기 전 상하좌우에 전등팩이 있어야 한다. **전등팩과 번호팩은 전기**, D의 **불빛팩은 공압**으로 잡는다.
- 암흑 구역을 지나려면 불빛팩을 바닥으로 향하게 잡고 이동 방향으로 육안 확인이 가능할 정도로 기울인다. 불빛팩 끝단이 든 칸부터 그 방향의 벽까지 밝히며, 번호팩 출발 칸이 그 범위에 들어가야 한다.
- 정렬 시작 시 전등팩과 상하좌우만 밝히고, 전등팩을 들면 전체를 어둡게 한다. 전등팩을 놓으면 해당 위치와 상하좌우를 다시 밝힌다. 번호팩을 불빛팩으로 비추고 목적지에 들고 왔으면 이동 경로만 밝게 남긴다. 번호팩을 내려놓은 뒤 **0.5초 이상** 기다리고 경로를 어둡게 한다. 완료 시 전부 밝히고 HMI 목표에 맞춘다. 불빛팩은 정렬 전후 D에 둔다.

### B · 두 층 이동과 네 방향 목표

- 시작 시 모든 팩을 파란 구역에 둔다. 눕힌팩은 1층과 2층에 하나씩 놓으며 2층 눕힌팩 밑의 두 팩 높이는 같아야 한다. 모든 정렬에 **전기 그리퍼만** 사용하고 높이는 최대 2층이다.
- 번호팩 1~12는 2층 팩 위를 넘어갈 수 없다. 이동하는 팩이 눕힌팩이면 예외다. 파란 구역 밖 세 칸에서 2층에 올릴 수 있는 것은 눕힌팩뿐이며, 그 위치의 2층 눕힌팩은 번호팩도 넘어갈 수 있다.
- HMI 목표는 중앙 초록 구역을 기준으로 시계 방향 **상·우·하·좌**를 본 네 개의 2층 모습이다. 소·중·대 및 눕힌팩을 두 개씩 표시해 총 8개로 보이게 한다. 눕힌팩은 각 층에 하나씩이며 화면에는 잘린 절반을 표시하고 ‘하’ 방향에는 표시하지 않는다. 실물의 해당 네 방향 모습이 HMI 목표와 같아야 한다.

### C · 구역별 빛의 세기

- 처음에 불빛팩을 D에서 노란 표시 칸으로 옮겨 C 정렬이 끝날 때까지 고정한다. 번호팩은 노란 칸을 제외한 자리에 배치하며 한 칸 이내의 빈자리로 옮긴다. 사각은 전기, 원형은 공압을 사용하며 동시 사용은 금지다. C가 끝나면 불빛팩을 D로 돌려놓는다.
- 과제지의 세 경로마다 **100에서 그 경로 칸에 놓인 팩의 감쇠값을 합산해 뺀다**. 목표 밝기는 **A 50, B 60, C 80**이다. A는 그림의 빨간 윗줄, B는 초록 대각선, C는 파란 오른쪽 세로줄이다. 대각선은 밝기를 계산하는 경로이며, 움직일 수 있는 방향은 과제지 C의 한 칸 규정을 따른다.
- 감쇠값은 사각 1·2가 5, 사각 3이 25, 원형 4·5가 10, 원형 6~8이 15, 원형 9가 20이다. HMI에는 C의 번호팩 위치를 실시간 표시한다.

## 충북 3과제 · 다리 이동 정렬

### 파레트와 팩

| 구역 | 폼지 구조·치수 | 팩 구성 |
| --- | --- | --- |
| A | 일렬 4자리, 폼지 약 40×160 mm. HMI는 좌우 4자리의 옆면 적층 표시 | 소형 원형 1~3, 중형 원형 4~6, 대형 원형 7·8 |
| B | 2×2 구역 4개, 총 16자리. 폼지는 2개 구역씩 한 도형으로 약 280×80 mm 2개 | 소형 사각 1~4, 중형 사각 5~7, 대형 사각 8~10 |
| C | 4×4 범위의 12자리, 외곽 약 190×190 mm | 종류표 기준 소형 원형 1·2, 중형 원형 3·4, 대형 원형 5, 소형 사각 6·7, 중형 사각 8·9, 대형 사각 10 |
| IT | 8자리, 작업 출구 6시 | A 정렬 후 원형팩 8개를 모두 받음 |

폼지 팩 중심 간격은 약 40 mm다. A는 옆면, B·C는 상단에 번호를 표시한다. **C는 개요 ⑦의 원형 1~4·사각 5~9와 종류표 및 기본 HMI 그림의 원형 1~5·사각 6~10이 다르다.** 표에는 종류표·그림의 10개 배치를 옮겼다. 경기에서는 확정 과제지에서 수량과 번호 범위를 확인한다.

### 정렬과 다리 이동

- **A**는 공압만 사용하고 팩을 최대 3층까지 쌓을 수 있다. 고정 목표는 HMI에서 왼쪽부터 아래층 **1·3·5·7**, 위층 **2·4·6·8**이다. 정렬 후 **전기 그리퍼만** 사용해 위층 왼쪽부터 2·4·6·8, 아래층 왼쪽부터 1·3·5·7 순으로 IT에 적재한다. IT 목표는 **12시 1번부터 시계 방향 1~8**이다.
- **B**는 초기 파란색 2×2 구역 두 곳에 각각 최대 3개를 놓는다. 전기만 사용하고 상하좌우로 옮긴다. 대각선 이동과 다른 팩을 넘는 동작은 금지다. 2×2 구역을 건널 때는 **초록색 줄에서만 겐트리를 다리로** 사용한다. 겐트리 이동 경로의 초록색 칸은 비어 있어야 하며, 팩을 잡은 상태에서도 겐트리는 움직일 수 있다. 고정 목표 그림은 위 행 왼쪽부터 1~8, 아래 행 첫 두 자리는 9·10이다.
- **C**는 사각 전기·원형 공압이며 동시 사용은 금지다. 일반 이동은 상하좌우이며 다른 팩을 넘을 수 없다. 예외로 **같은 높이의 팩이 상하좌우로 두 개 이상 이어지면** 그 팩들을 다리 삼아 넘을 수 있다. 출발과 도착은 각각 다리에 상하좌우로 한 칸 이내여야 한다. 한 개만 넘거나 높이가 다른 다리를 연달아 통과할 수 없다. HMI 목표에 맞춘다.
- HMI에는 A의 적층, B·C와 IT의 현재 배치를 실시간으로 표시한다. A의 정렬 완료와 IT에 옮긴 최종 배치는 각각 채점한다.

## 검사와 채점

네 과제의 작업 시간은 각각 3시간이며 **기초 → 기본동작 → 랜덤동작** 순이다. 기본·랜덤 준비 시간은 5분·7분, 평가 시간은 10분·15분이다. HMI는 준비 → 주행 → 완료의 상태와 완료 후 정수 초 단위 주행시간을 표시한다. 시작·종료 부저는 각각 0.5초이며 시간 측정에 포함한다. 기초검사 자세·속도와 공통 평가 절차는 [2차시 검사와 채점](session-02.md#검사와-채점)을 참조한다.

| 과제 | 기초 / 기본 / 랜덤 | 기본·랜덤 각각의 동작 채점 |
| --- | --- | --- |
| 충남 2 | 16 / 7 / 7점 | 초기 1, A 1, B 1, C 1.5, 실시간 1.5, 완료·시간 1 |
| 충남 3 | 18 / 8.4 / 8.5점 | 초기 1.2, A·B·C 각 1.4, IT 모양 표시 0.3, 실시간 1.5, 완료·시간 기본 1.2 / 랜덤 1.3 |
| 충북 2 | 16 / 7 / 7점 | 초기 1, A 1.3, B 1.4, C 0.8, 실시간 1.5, 완료·시간 1 |
| 충북 3 | 18 / 8.4 / 8.5점 | 초기 1.2, A 정렬 0.6 및 IT 최종 적재 0.6, B 1.8, C 1.5, 실시간 1.5, 완료·시간 기본 1.2 / 랜덤 1.3 |

- 실시간 표시는 올바르게 정렬한 파레트에 각 0.5점을 부여한다. 충북 3 과제지는 IT까지 표시하도록 하고 동작 확인서는 A~C 표시 1.5점으로 기록한다.
- 충남·충북 2과제는 기본·랜덤 합계 7점 이상일 때 시간 기본점수 4.9점을 적용한다. 합계 14점이면 합산 주행시간 순위 최대 0.1점 대상이다. 3과제에는 개소당 감점과 시간 순위 점수가 적용된다. 충북 3의 순위 자격은 **16.9점**이다. 충남 3은 기본·랜덤 만점 합계가 16.9점이지만 채점 기준 (4-2)에 순위 자격이 **14점**으로 적혀 있으므로 현장 확정 채점표에서 확인한다.
- 실행 후 HMI 초기값 수정으로 재평가(최대 2회), 시작 또는 종료 부저 누락(최대 1회), 배치 후 적색 원·사각 표식이 보이는 경우(해당 팩 수)는 개소당 0.1점 감점이다.
