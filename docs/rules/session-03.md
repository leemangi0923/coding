## 광주 2과제 · 대형 사각팩 이동정렬

### 파레트와 배치

| 구역 | 폼지 구조·치수 | 팩과 초기 배치 |
| --- | --- | --- |
| A | 3행×4열, 약 160×120 mm, 중심 간격 40 mm | 중형 사각 1~4와 중형 원형 5~8을 1층에 랜덤 배치. 무표기 대형 사각 2개를 각각 팩 두 개 위에 눕혀 가로·세로 하나씩 놓음 |
| B | 5행×5열 범위의 21자리, 약 200×200 mm, 중심 간격 40 mm. 중앙 적색 3×3, 네 변에 청색 3자리씩 | 소형 사각 1~6과 소형 원형 7~12를 청색에 배치. 무표기 대형 사각 2개는 적색에 눕혀 가로·세로 하나씩 배치 |
| C | 2행×3열, 약 140×90 mm, 중심 간격 50 mm | 대형 원형 1~6을 1층에, 무표기 대형 사각 2개를 2층에 랜덤 배치 |

실물 팩 32개를 쓴다. 번호는 팩 상단에 적고 대형 사각팩은 표기 없이 둔다. B의 청색·적색 배치 조건은 초기와 목표 맵에 모두 적용한다. C의 두 층은 HMI에 별도 격자로 표시한다.

### 이동과 목표

- **A**는 사각에 전기, 원형에 공압을 쓰고 두 그리퍼를 동시에 사용할 수 없다. 대형 사각팩은 두 팩 위로 옮긴다. 대형팩을 옮겨 그 아래 있던 두 숫자팩을 이동 가능한 상태로 만들며, 과제지는 다른 대형팩을 움직이면 이동 가능한 팩이 바뀐다고 명시한다. 중형팩은 상하좌우로 이동하고 잡은 팩 하단은 중형팩 상단보다 낮게 유지한다. 고정 목표는 1층 첫째 행에 1~4, 둘째 행에 5~8이다. 2층은 좌상단 두 행의 1열에 세로, 첫째 행 2·3열에 가로 대형팩을 놓는다.
- **B**는 사각에 전기, 원형에 공압을 쓰고 한 번에 한 팩만 든다. 상하좌우로 이동한다. 적색 구역에서 소형팩은 대형 사각팩 위로만 옮길 수 있다. 위에 팩이 올라간 대형 사각팩은 고정되며, 대형팩을 옮길 때 가로·세로 방향을 유지한다. 이동 중 팩 하단은 소형팩 상단보다 낮게 한다. HMI 목표와 일치시킨다.
- **C**는 사각에 전기, 원형에 공압을 쓴다. 상하좌우 이동 외에 2층 원형과 그 아래 사각, 또는 2층 사각과 그 아래 원형을 서로 교환할 수 있다. 양쪽 층을 HMI 목표와 일치시킨다.
- A·B·C의 현재 배치를 실시간으로 표시한다. A 고정 목표는 동작 조건 (7), B·C의 기본 배치와 목표는 HMI 조건의 그림을 참조한다.

## 광주 3과제 · 파레트 정렬

### 파레트와 배치

| 구역 | 폼지 구조·치수 | 팩과 초기 배치 |
| --- | --- | --- |
| A | 5행×5열 범위의 +자, 중심 포함 9자리, 약 200×200 mm | 소형 사각 1~3, 소형 원형 4~6. 초기·목표에서 가운데를 비움 |
| B | 가로 5자리, 약 200×40 mm. 정면 HMI는 3층×5열 | 중형 사각 1~6, 중형 원형 7~12. X 한 개를 HMI의 3층에 지정하고 그 열은 1·2층도 비움 |
| C | 5행×5열 범위의 ×자, 중심 포함 9자리, 약 200×200 mm | 대형 사각 1~4, 대형 원형 5~8. 초기·목표에서 가운데를 비움 |
| D | HMI 기준 3줄, 위 2자리·가운데 6자리·아래 2자리. 폼지는 90° 돌아간 방향으로 약 200×239 mm | 소형 사각 1~3, 대형 사각 4·5, 소형 원형 6~8, 대형 원형 9·10. 10자리 모두 사용 |
| IT | 인덱스테이블 8자리. A의 번호 1~6을 HMI에 랜덤 입력 | 시작할 때 IT 실물은 비어 있고 정렬한 A의 팩 6개를 옮겨 받음 |
| 겐트리 | 1~6 표식 띠, 약 180×40 mm | B·C·D의 내려놓을 열을 지정 |

실물은 A 6개, B 12개, C 8개, D 10개로 총 **36개**이며 숫자는 상단에 적는다. A~D의 자리 중심 간격은 약 40 mm다. 겐트리 열 표식 간격은 약 30 mm다.

### 이동과 장치

- **A**는 사각에 전기, 원형에 공압을 쓰고 한 번에 한 팩만 든다. 상하좌우로 이동하며 중앙은 통과만 할 수 있다. 잡은 팩 하단은 A의 가장 작은 팩 상단보다 낮게 유지한다. HMI 목표 배치로 정렬하고 **1→2→3→4→5→6** 순서로 A 팩을 IT에 이송한다. IT의 시작 HMI 배치와 이송 중 실시간 표시를 과제지 화면에 맞춘다.
- **B**는 전기·공압 그리퍼를 사용한다. 최대 3층이며 X가 표시된 열에는 팩을 놓지 않는다. 정면에서 3층부터 2층, 1층 순서로 내려오고 층마다 왼쪽에서 오른쪽으로 1~12를 채운다. X 열은 모든 층에서 건너뛴다.
- **C**는 사각에 전기, 원형에 공압을 쓰고 한 번에 한 팩만 든다. 표시 라인 또는 실제 연결된 대각선으로만 움직인다. 잡은 팩 하단은 C의 가장 작은 팩 상단보다 낮게 유지한다. HMI 목표에 맞춘다.
- **D**는 전기·공압을 사용해 두 팩의 위치를 교환한다. 위 1번 줄↔가운데 2번 줄, 아래 3번 줄↔가운데 2번 줄의 교환이 가능하다. 같은 줄끼리 또는 위↔아래 줄의 교환은 금지다. HMI 목표에 맞춘다.
- **B·C·D에 팩을 놓기 전** 겐트리로 놓을 열을 표시한다. 과제지 동작 조건 (12)에 각 파레트의 열 표시 동작이 그림으로 제시된다. A·B·C·D·IT의 작업 상태는 HMI에 실시간으로 반영한다. 완료화면 예시는 A의 목표 배치를 화면에 유지한다.

## 대구 2과제 · 밑줄 정렬

### 파레트와 배치

| 구역 | 폼지 구조·치수 | 팩과 초기 배치 |
| --- | --- | --- |
| A | 3행×3열, 폼지 외곽 약 120×116 mm, 중심 간격 30 mm | 중형 사각 1~4·소형 사각 6은 세움. 중형 사각 5는 연결된 중형 두 개 위에 눕힘. 대형 사각 X는 초록색 8자리 중 선으로 연결된 두 칸에 눕혀 고정 |
| B | 3행×3열, 폼지 외곽 약 141×140 mm, 중심 간격 40 mm | 소형 사각 4~8은 세우고 대형 사각 1~3은 눕힘 |
| C | 4행×4열, 폼지 외곽 약 180×182 mm, 중심 간격 45 mm | 소형 원형 1~6, 중형 원형 7~12, 대형 원형 13~18. 초록색 네 자리 중 한 곳에 대형 사각 2개를 쌓아 X로 고정 |

실물 팩은 A 7개, B 8개, C 20개로 총 **35개**다. 세 파레트 모두 적층은 최대 **2개**다. 눕힌 A의 5번과 B의 1~3번은 실물 숫자의 밑줄 방향까지 HMI와 같아야 한다. A와 C의 X는 실물 장애물이고, A에서는 X 위에 팩을 적재할 수 없다. 기본·랜덤의 초기·목표 배치를 구분하고 HMI에는 1층과 2층을 각각 표시한다.

### 그리퍼·방향·높이

- **A는 공압만 사용**한다. 중형 1~4는 파란 선을 따라 상하좌우로 이동하고 하단은 눕힌 5번의 높이인 **20 mm 미만**으로 유지한다. 중형 5는 파란 선으로 연결된 중형팩 두 개 위에서만 이동·배치한다. 5의 허용·금지 전이는 가로·세로별 동작 조건 (7)-④ 그림을 따른다. 소형 6의 배치는 세우는 조건이 명시되어 있고 (7)의 번호별 이동 표에는 별도 항목이 없다.
- **B는 전기만 사용**한다. 소형은 파란 선에 따라 상하좌우로 이동하며 하단은 **20 mm 미만**이다. 대형은 선에 따라 움직이고 하단은 **60 mm 미만**으로 유지하며 이미 두 개가 쌓인 곳 위를 통과할 수 없다. 대형은 연결된 바닥 두 칸, 연결된 소형팩 두 개 위, 또는 두 칸을 차지하는 대형팩 위에 눕혀 놓는다. 방향별 허용·금지 전이는 동작 조건 (8)-③ 그림을 따른다.
- **C는 전기만 사용**한다. 원형팩은 파란 선을 따라 상하좌우로 움직이며 대각선 이동과 2층으로 쌓인 팩을 넘는 동작은 금지다. 이동하는 팩의 하단은 **80 mm 미만**으로 유지한다. X는 두 팩이 쌓인 상태로 움직이지 않는다.

## 대구 3과제 · 오징어 게임 정렬

### 파레트와 배치

| 구역 | 폼지 구조·치수 | 팩과 초기 배치 |
| --- | --- | --- |
| ● | 5행×5열, 약 202×205 mm | 소·중·대 사각 각 4개, 총 12개 |
| ▲ | 4행×4열, 약 160×163 mm | 소·중·대 원형 각 3개, 총 9개. 크기마다 하나씩 ‘소X’·‘중X’·‘대X’를 붙여 고정. H 4자리 |
| ■ | 5행×4열, 약 160×205 mm | 사각과 원형 각각 소·중·대 2개씩, 총 12개 |
| IT | 8자리 중 3자리 사용. 출구 6시 | ‘소’·‘중’·‘대’ 원형 각 1개. 기본 배치 그림 기준 소 9시, 중 12시, 대 3시. 랜덤은 심사위원 배치 |
| 겐트리 | 폼지 외곽 약 402×54 mm, 소·중·대 영역 각각 약 120×40 mm | 집을 팩 크기에 맞는 표식 구역에 겐트리 폼지를 위치시킴 |

실물 팩은 IT 3개를 포함해 총 **36개**다. 파레트의 팩 중심 간격은 약 40 mm다. ▲의 고정팩끼리는 서로 다른 고정팩의 인접 8자리(대각선 포함)에 배치할 수 없다. ▲의 초기 배치에서는 같은 크기의 세 팩이 과제지의 직각삼각형 모양을 이미 이루고 있으면 안 된다.

### 이동과 집기 조건

- 사각은 전기, 원형은 공압 그리퍼를 쓴다. 파란 라인이 있는 상하좌우 방향으로만 이동한다. 다른 팩을 넘거나 대각선으로 이동할 수 없다. 잡은 팩의 하단은 해당 파레트의 가장 작은 팩 상단보다 낮게 유지한다.
- 홀 H는 통과할 수 있고 내려놓을 수 없다. ‘소X’·‘중X’·‘대X’는 이동할 수 없다.
- **팩에 접촉해 집기 전에 두 조건을 모두 맞춘다.** IT 6시 출구에 집을 팩과 같은 크기 표기의 팩이 있고, 겐트리 폼지가 같은 표기의 구역에 들어와 있어야 한다. IT·겐트리와 세 파레트의 상태를 HMI에 실시간으로 표시한다.

### 정렬 인정 조건

- **●**는 같은 크기의 사각팩 네 개씩으로 과제지의 모양 1 또는 모양 2를 이룬다. 그림은 각각 빈 중심의 상하좌우에 한 칸씩 떨어진 배치와 두 칸씩 떨어진 배치를 보여준다.
- **▲**는 크기마다 고정팩 하나와 움직일 수 있는 팩 두 개로 직각삼각형 하나를 만든다. 원본 표의 아홉 종류 중 세 그룹이 서로 다른 종류여야 한다. 90°·180°·270° 회전 또는 좌우 대칭으로 겹치는 삼각형은 같은 종류다. 중심 간격 한 칸을 단위로 하면 원본 그림의 두 직각변 길이는 순서대로 (1, 1), (2, 1), (3, 1), (√2, √2), (√2, 2√2), (2, 2), (3, 2), (√5, √5), (3, 3)이다. 이는 완성 배치의 모양 조건이며 이동할 때는 파란 선을 따른다.
- **■**는 같은 크기의 사각 2개와 원형 2개를 네 꼭짓점에 둔다. 2×2, 3×3, 4×4 크기의 격자 정사각형을 각각 한 개 만든다. 격자에 비스듬한 마름모 방향은 인정하지 않는다.

## 기초검사와 채점

네 과제 모두 수행 3시간이며 **기초 → 기본동작 → 랜덤동작** 순으로 평가한다. 기본·랜덤 준비 시간은 5분·7분, 평가 시간은 10분·15분이다. HMI는 팩 배치와 관련 장치 상태를 다음 동작 전에 갱신한다. 로봇 상태는 **준비 → 주행 → 완료**이며 시작·종료 부저는 각각 0.5초다. 두 부저를 포함한 주행시간은 완료 후 정수 초로 표시한다. 기초검사 자세·속도와 공통 평가 절차는 [2차시 검사와 채점](session-02.md#검사와-채점)을 참조한다.

| 과제 | 기초 / 기본 / 랜덤 | 기본·랜덤 각각의 동작 채점 |
| --- | --- | --- |
| 광주 2 | 16 / 7 / 7점 | 초기 0.5, A·B·C 각 1.5, 실시간 1.5, 완료·시간 0.5 |
| 광주 3 | 16 / 7 / 7점 | 초기 0.5, A·B·C·D의 정렬과 실시간 표시 각 1.1, IT 0.55, 겐트리 0.55, 완료·시간 1 |
| 대구 2 | 16 / 7 / 7점 | 초기 1, A 1, B 1.5, C 1, 실시간 1.5, 완료·시간 1 |
| 대구 3 | 18 / 8.4 / 8.5점 | 초기 1.2, ● 1.3, ▲ 1.8, ■ 1.4, 실시간 1.5, 완료·시간 기본 1.2 / 랜덤 1.3 |

- 광주 2, 대구 2, 대구 3의 실시간 표시 점수는 파레트별 0.5점이며 해당 파레트의 올바른 정렬을 전제로 한다. 대구 3은 IT·겐트리 실시간 표시도 요구한다. 광주 3은 A~D의 실시간 표시가 각 파레트의 정렬 점수에 포함된다.
- 광주 2의 기본·랜덤 초기 배치와 광주 3의 기본 초기 배치는 항목 제목 0.5점과 설명 문장 1점이 엇갈린다. 표에는 동작 확인서와 7점 총계에 맞는 0.5점을 적었다. 경기에서는 확정 채점표를 따른다.
- 두 지역의 2과제는 기본·랜덤 합계 7점 이상일 때 시간 기본점수 4.9점을 적용한다. 광주 3은 완성도를 기준으로 4.9점 범위에서 차등 적용한다. 대구 3의 채점 기준은 개소당 감점을 명시한다. 두 주행시간을 합한 시간 순위 점수는 최대 0.1점이며 광주 2·3과 대구 2는 기본·랜덤 합계 14점, 대구 3은 16.9점일 때 대상이다.
- 실행 후 초기값 수정으로 재평가(최대 2회), 시작 또는 종료 부저 누락(최대 1회), 배치 후 적색 정렬 표식이 보이는 경우(해당 팩 수)는 개소당 0.1점 감점이다.
