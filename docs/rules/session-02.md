기구 배치도의 작업대 범위는 네 과제 모두 **1200×900 mm**다. 아래 폼지 치수는 원본 도형을 100% 배율로 환산한 폭×높이 참고치다. 행·열 방향과 파레트 위치는 과제지의 기구 배치도를 따르며, 경기에는 당일 지급 폼지를 사용한다.

## 경북 2과제 · 숫자 회전 정렬

### 파레트와 배치

| 구역 | 폼지 구조 | 팩 구성 |
| --- | --- | --- |
| A1 | 3행×4열의 라인과 중심 표식 12개 | 중형 사각 1~6, 무표기 대형 사각 1개 |
| A2 | A1과 같은 3행×4열, 중심 표식 12개 | 중형 원형 1~6, 무표기 대형 사각 1개 |
| B | 첫째·셋째 행 각각 7자리, 가운데 행은 1·4·7열에 3자리. 총 17개 중심 표식 | 소형 원형 1·3·5·7, 대형 원형 2·4·6·8, 대형 사각 ‘홀’·‘짝’ 각 1개 |
| C | 앞·뒷단 각 7자리, 중심 표식 14개 | 소형 사각 1~6, 소형 원형 7·8, 대형 원형 9·10, 무표기 대형 사각 2개 |

A·B의 숫자와 ‘홀’·‘짝’은 상단, C 숫자는 정면에 표시한다. A의 숫자팩은 처음에 대형팩 위에 놓을 수 없고 A1 밑줄의 초기 방향은 자유다. C의 초기 팩은 모두 1층에 놓으며 같은 열에서 뒷단이 앞단보다 높을 수 없다.

### A1·A2 교대와 A1 회전

- 사각은 전기, 원형은 공압 그리퍼로 잡고 한 번에 한 팩만 든다. 표시된 라인을 따라 이동하고 출발·도착 위치는 달라야 한다. 잡은 팩의 하단은 중형팩의 상단보다 낮게 유지한다.
- 숫자팩은 대형팩 위를 통과할 수 있으며 그 위에 내려놓을 수 없다. 대형팩은 다른 팩 위를 통과할 수 없고 한쪽 끝을 기준으로 상하좌우 라인을 따라 움직인다.
- **A1 → A2**를 한 쌍으로 반복한다. A1에서 숫자팩을 옮겼으면 A2에서도 숫자팩, A1에서 대형팩을 옮겼으면 A2에서도 대형팩을 옮긴다. A1 숫자팩을 움직일 때마다 밑줄 방향이 달라야 한다.
- 종료 시 A1·A2의 같은 번호가 각각 같은 자리에 있고 대형팩 위치도 같아야 한다. A1의 모든 숫자팩 밑줄은 아래 방향이다. 최종 공통 배치는 선수별로 달라질 수 있다.

### B·C 이동과 HMI

- **B**의 짝수 및 ‘짝’은 전기, 홀수 및 ‘홀’은 공압 그리퍼를 쓴다. 한 번에 한 팩씩 라인을 따라 움직이며 팩 하단은 소형팩 상단보다 낮게 유지한다. 숫자팩이 같은 홀짝의 대형 사각팩을 지날 때는 그 상단을 통과할 수 있다. 목표 그림에서 위쪽 라인은 왼쪽부터 1·3·5·7·홀, 아래쪽 라인은 2·4·6·8·짝 순으로 놓인다. 빈자리와 대형팩의 거치 위치는 동작 조건 (8)의 그림을 따른다.
- **C**는 사각을 전기, 원형을 공압으로 잡는다. 정렬 중에도 같은 열의 뒷단은 앞단보다 높을 수 없고 각 적층의 총 높이는 **80 mm 이하**다. 최종 배치는 동작 조건 (9)의 그림을 따른다.
- HMI에 A1·A2·B·C의 현재 상태를 갱신한다. C는 위에서 본 격자로 표시하고 대형팩의 가로·세로 방향, 숫자팩 위의 적층 등은 HMI 조건 (2)의 예시를 따른다. A 채점은 A1·A2를 함께 본다.

## 경북 3과제 · 한글 키보드 정렬

### 파레트와 배치

| 구역 | 폼지 구조 | 팩 구성 |
| --- | --- | --- |
| A | 3행×4열, 12자리 모두 채움 | 소형 사각 ㄱ·ㄴ, 소형 원형 ㄷ·ㅁ·ㅈ, 중형 원형 ㄹ·ㅇ·ㅋ·ㅂ·ㅍ, 대형 원형 ㅊ·ㅌ |
| B | 계단형, 표식 14자리 모두 채움. 적색 정렬선 4개 | 소형 사각 ㅣ·ㅡ·ㅠ·ㅛ, 중형 사각 ㅑ·ㅕ·ㅓ·ㅏ·ㅗ·ㅜ, 대형 원형 ㅐ·ㅎ·ㅅ·ㅔ |
| C | 4행×3열, 12자리 중 10개 사용 | 대형 사각 1~6, 소형 원형 7~9, 중형 원형 0 |
| IT·G | 인덱스테이블과 겐트리에 거치된 G파레트 사용. G에 일렬 4자리와 적색 정렬선 | 정렬 도중 A·B의 팩을 각각 임시 거치 |

A·B·C의 팩 표시는 상단에 붙인다. 기본·랜덤 검사에서 각각 제시된 초기 위치로 시작하며 A·B·C 목표는 동작 조건 (7)~(9)의 그림에 정해져 있다. C 목표는 위부터 `1 2 3`, `4 5 6`, `7 8 9`, `0 빈칸 빈칸`이다.

### 파레트별 정렬

- **A ↔ IT**는 출발 구역에 다시 놓을 수 없다. A→IT는 전기, IT→A는 공압을 쓴다. A에 12개가 모두 놓인 상태에서 첫 번째로 집은 자리의 행과 열 전체를 IT에 옮긴다. 교차 칸을 한 번 세면 총 6개다. IT에 옮긴 팩을 전부 A에 돌려놓은 뒤 다음 이동 묶음을 시작한다.
- **B ↔ G**도 출발 구역에 다시 놓을 수 없다. B→G는 전기, G→B는 공압을 쓴다. G에는 최대 4개를 올리고 **G가 비었을 때만 겐트리를 이동**한다. 이송할 때 B와 G의 적색 정렬선을 맞춘다. 팩 하단은 가장 낮은 팩의 상단보다 낮게 유지한다.
- **C**는 상하좌우로만 움직이며 사각은 전기, 원형은 공압을 쓴다. 팩 하단을 가장 낮은 팩의 상단보다 낮게 유지한다. A·B·C 정렬은 한 번에 한 팩만 든다.

### 두 글자 입력과 HMI

- 모두 정렬한 뒤 제시된 C 숫자팩(0~9)을 **전기 그리퍼**로 집는다. 글자마다 **초성 → 중성 → 종성** 순서로 해당 문자팩 위에 숫자팩을 내려놓고 다시 집는다. 받침이 없는 글자는 종성 동작을 생략한다. 두 글자가 끝나면 C의 원래 자리에 숫자팩을 돌려놓는다.
- 초성·종성은 ㄱ·ㄴ·ㄷ·ㄹ·ㅁ·ㅂ·ㅅ·ㅇ·ㅈ·ㅊ·ㅋ·ㅌ·ㅍ·ㅎ, 중성은 ㅏ·ㅑ·ㅓ·ㅕ·ㅗ·ㅛ·ㅜ·ㅠ·ㅡ·ㅣ·ㅐ·ㅔ로 조합한다. 쌍자음·겹받침 및 표에 없는 모음은 제외한다.
- HMI의 A·B 자모와 두 글자 입력은 한글입력기를 사용한다. 랜덤 검사에서는 이 입력 조건이 A·B 정렬과 글자 동작의 배점에도 적용된다. 실시간 표시는 A를 정렬할 때 IT, B를 정렬할 때 G까지 포함한다. 글자를 찍은 뒤에도 A·B·C의 팩 정보를 남긴다.

## 전북 2과제 · 탑 정렬

### 파레트와 배치

| 구역 | 폼지 구조·치수 | 팩 구성 |
| --- | --- | --- |
| A | 3행×5열, 약 200×120 mm, 최대 3층 | 중형 사각 1~4, 중형 원형 5~8, 대형 원형 9~12, 대형 사각 ○·△·◇·□ |
| B | 6행×6열 범위 안의 26자리, 약 240×240 mm. 노란 목표 구역 5자리 | 소형 사각 1·2, 중형 사각 3, 소형 원형 4, 중형 원형 5. HMI에만 지정하는 지울 숫자 15개 |
| C | 약 160×120 mm. RED·BLUE 각 4자리, 높이 기준용 별도 자리 1개 | 소형 사각 1~4, 대형 원형 5·6, 무표기 대형 사각 가로·세로 배치. 별도 기준 자리의 소형·중형 원형 2개 |

전북 두 폼지의 용지 설정은 A3이고 중심 피치는 약 40 mm다. 전북 2과제 A의 문자팩과 B의 숫자팩에는 위쪽, A·C의 숫자팩에는 옆면에 표기한다. C의 90 mm 기준 탑은 소형·중형 원형을 쌓아 만들고 RED 앞 지정 자리에 둔다.

### A · 숫자 교환과 문자팩 적층

- 숫자팩은 1층의 빈자리로 이동하거나 사각과 원형처럼 **서로 다른 모양의 숫자팩끼리** 교환한다. 이 교환에만 두 그리퍼로 동시에 두 팩을 잡을 수 있다.
- 문자팩은 2층 또는 3층에 놓는다. 2층에서는 같은 높이의 숫자팩 두 개 위에 놓는다. 3층에서는 그 조건을 충족한 문자팩 하나 위에 올리거나, 같은 높이의 적법한 두 묶음을 연결해 놓는다. 초기 배치와 정렬 모두 적용한다.
- HMI의 층별 목표에 맞춘다. 문자팩은 위치를 채점하며 표기 방향은 자유다. A의 동작 조건 (7)에는 단독 이동의 그리퍼 종류가 따로 지정되어 있지 않다.

### B · 숫자 삭제와 오름차순 배치

- 숫자팩 5개를 바닥에 놓고, 팩과 겹치지 않는 다른 15자리에 HMI로 각 숫자 1~5를 **3개씩** 지정한다. 원형은 전기, 사각은 공압을 사용한다. 한 번에 한 팩, 상하좌우 이동만 가능하고 매 이동 후 내려놓는다. 파레트 밖 이동과 다른 팩 위의 배치는 금지다.
- 숫자팩을 자기 번호가 표시된 칸에 내려놓으면 해당 HMI 숫자를 삭제한다. 제약은 **팩마다 자기 숫자를 지운 횟수**에 따라 바뀐다.

| 해당 팩이 지운 숫자 | 한 번의 이동 제약 |
| --- | --- |
| 0개 | 동작 조건 (8)의 공통 이동 규칙 적용 |
| 1개 | 최대 2칸. 다른 팩과 허공을 넘을 수 있음 |
| 2개 | 최대 2칸. 다른 팩과 허공을 넘을 수 없음 |
| 3개 | 최대 1칸. 다른 팩과 허공을 넘을 수 없음 |

15개를 전부 지우면 1차 정렬이 끝난다. 2차는 노란 구역에 1~5를 오름차순으로 놓으며 자리 순서는 동작 조건 (8)-⑥의 그림을 따른다. 과제지에는 2차 시작 시 삭제 횟수를 초기화하는 동작이 따로 적혀 있지 않다.

### C · 80 mm 적층과 90 mm 이동 높이

- 사각은 전기, 원형은 공압을 사용하고 한 번에 한 팩만 든다. 폼지 기준 상하좌우 또는 Z축 상하로만 움직이며, 위에 팩이 놓여 있는 팩은 집을 수 없다.
- 대형 사각팩은 같은 높이의 두 자리 위에 걸쳐 놓는다. 초기 배치에 가로·세로 방향을 모두 사용하고 각 팩의 방향은 이동 후에도 유지한다.
- RED·BLUE 적층은 정렬 내내 **80 mm 이하**다. 이동 중에는 잡은 팩의 **상단이 90 mm 이하**가 되게 한다. 기준 탑은 RED·BLUE 적층 밖에 있다.
- RED와 BLUE는 HMI에 각각 정면도를 표시한다. 최종 배치는 동작 조건 (9)의 목표 그림을 사용한다.

| C | 과제지 방향에서 6행×5열 범위, 3개 세로 줄과 연결 칸 2개. 총 20자리, 폼지 인쇄 방향 약 240×200 mm | 소형 사각 1·2, 소형 원형 3·4, 대형 사각 장애물 X 3개. HMI 지정 ↔·↕ 각 2개 |
| IT | 인덱스테이블, 작업 출구 6시 | 대형 원형 1~4 |

A·B의 숫자는 옆면, 문자는 상단에 쓴다. C와 IT는 모두 상단에 쓴다. C의 숫자팩과 장애물, 특수요소 초기 위치는 과제 개요의 붉은 구역에 지정한다. 특수요소는 팩과 겹치지 않게 표시하고 3번 열에 최소 1개를 포함한다. 목표는 HMI에서 확인한다.

### A · 겐트리 표식과 적층

- **팩을 잡기 전에** 겐트리의 붉은 선을 집을 팩의 숫자·문자와 일치시킨다. 사각은 전기, 원형은 공압을 쓰며 한 번에 한 팩만 잡는다. 다른 팩이 위에 올라가 있으면 해당 팩을 옮길 수 없다.
- 숫자팩은 1·2층에 놓는다. 상하좌우로만 이동하며 다른 팩을 뛰어넘을 수 없다. 문자팩은 경로의 방향·넘기 제한 없이 움직일 수 있다.
- 문자팩을 세워 2층에 놓을 때는 해당 자리 1층에 받침이 있어야 하며, 세운 팩은 2층과 3층을 차지한다. 눕혀 3층에 놓을 때는 인접한 두 자리의 2층에 각각 받침이 있어야 한다. 적층은 항상 최대 3층이다. 초기값과 목표값에서는 두 문자팩을 모두 3층에 눕힐 수 없다.

### B · 대형팩 단독·집단이동

- 사각은 전기, 원형은 공압을 쓴다. 숫자팩의 독립 이동은 1층에서 상하좌우 한 칸씩이다. 대형 사각팩은 색이 같은 두 하단 팩 위에 놓는다.
- **단독이동**은 대형 사각팩만 옮긴다. **집단이동**은 대형 사각팩과 받치고 있는 숫자팩을 함께 옮겨 대형 사각팩을 기존 방향에서 **90°** 돌려 놓는다. 집단이동의 하단 숫자팩에는 독립 이동의 한 칸 규칙을 적용하지 않는다. 두 방식의 거치 예시는 동작 조건 (8)-③ 그림을 따른다.
- 숫자팩 독립 이동을 두 번 하면 그다음 대형 사각팩을 한 번 옮겨야 한다. 앞서 대형팩을 옮겨도 되고, 옮기면 숫자팩 이동 횟수는 0으로 돌아간다. 집단이동의 하단 팩은 카운트에서 제외한다. HMI에 카운트를 표시하며 최종 채점은 숫자팩과 대형팩의 위치를 본다.

### C · 장애물 교환과 특수요소

- 숫자팩을 집기 전에 **IT 6시 출구에 같은 번호의 팩이 오도록** 맞춘다. 사각은 전기, 원형은 공압을 사용하며 숫자팩과 X를 교환할 때만 두 그리퍼를 동시에 쓴다.
- 일반 이동은 파레트 안에서 상하좌우 한 칸씩이다. 다른 숫자팩을 넘을 수 없고 매번 내려놓는다. 한 칸 앞에 X가 있으면 숫자팩과 교환하고 둘 다 내려놓는다. X는 교환을 통해서만 움직인다.
- **↔**를 획득한 숫자팩은 최대 3칸까지 이동한다. 경로에 X가 있으면 X와 인접한 위치까지 움직여 교환하며 교환한 즉시 이동을 끝낸다.
- **↕**를 획득한 숫자팩은 한 칸 앞의 X 하나를 같은 방향으로 뛰어넘고 내려놓을 수 있다. 이 특수규칙을 가진 동안 X와 교환할 수 없다.
- 특수요소가 표시된 칸에 내려놓으면 그 팩에 해당 규칙이 적용된다. 그 칸을 벗어난 뒤에도 유지되며, 다른 숫자팩이 해당 특수요소 자리에 놓이면 이전 팩은 일반 규칙으로 돌아간다. 최종 채점은 숫자팩 위치를 기준으로 한다.

## 검사와 채점

네 과제 모두 수행 시간은 3시간이며 **기초 → 기본동작 → 랜덤동작** 순으로 평가한다. 기본은 과제지의 기본 배치, 랜덤은 심사위원의 입력값을 사용한다. HMI는 동작 중 배치를 실시간 갱신하고 상태를 **준비 → 주행 → 완료**로 표시한 뒤 정수 초로 주행시간을 표시한다. 시작·종료 부저는 각각 0.5초다. 공통 평가 절차는 [1차시의 공통 검사 규칙](session-01.md#네-과제-공통-검사와-시간감점)을 참조한다.

- **2과제 기초검사**는 홈 `posj(0,0,0,0,0,0)`, 설정 `posj(90,0,90,0,0,0)`, 두 그리퍼의 지면 방향 자세와 ON/OFF, 부저 ON/OFF, BASE 각 축 ± 방향 조그, 화면 전환 및 종료 LED를 확인한다. 관절 속도·가속도는 20~50, 조그 선속도·가속도는 50~200, 축 방향 기울기 허용 범위는 ±5°다.
- **3과제 기초검사**는 홈 `posj(90,0,90,90,90,0)`, 설정 시 IT 6시 출구 상단, IT 한 자리 자연수만큼 정회전(시계 방향)·역회전(반시계 방향), 겐트리 좌·원점·우, PLC 리셋, 화면 전환과 종료 LED를 확인한다. 홈·설정의 관절 속도·가속도는 20~50이다. IT 6시 자리에 실물 소형 사각팩을 올리고 HMI에 빨간 사각으로 표시한다. 리셋은 IT와 겐트리의 실제 원점 복귀 및 HMI 초기화를 포함한다.

| 과제 | 기초 / 기본 / 랜덤 | 기본·랜덤 각각의 배점 |
| --- | --- | --- |
| 경북 2 | 16 / 7 / 7점 | 초기 1, A 1.5, B 0.5, C 1.5, 실시간 1.5, 완료·시간 1 |
| 경북 3 | 18 / 8.4 / 8.5점 | 초기 1.4, A 1.4, B 1.4, C 0.7, 글자 입력 1, 실시간 1.5, 완료·시간 기본 1 / 랜덤 1.1 |
| 전북 2 | 16 / 7 / 7점 | 초기 1, A 1, B 1, C 1.5, 실시간 1.5, 완료·시간 1 |
| 전북 3 | 16 / 7 / 7점 | 초기 1, A 1, B 1.3, C 1.2, 실시간 1.5, 완료·시간 1 |

- 실시간 표시는 A·B·C 각 0.5점이며 해당 파레트가 올바르게 정렬되어야 부여한다. 완료·시간 기록은 정렬 또는 실시간 표시 등 해당 평가의 동작 항목에서 일부라도 점수를 받은 경우에 부여한다.
- 경북 2·전북 2·전북 3은 기본·랜덤 합계가 7점 이상이면 4.9점 기준으로 감점을 적용하고, 합계 14점일 때 합산 주행시간 순위 점수를 최대 0.1점 부여한다. 경북 3은 과제 수행 점수에 감점 항목을 적용하고 합계 16.9점일 때 순위 점수를 최대 0.1점 부여한다.
- 감점은 실행 후 HMI 초기값 수정으로 재평가(최대 2회), 시작 또는 종료 부저 누락(최대 1회), 배치 후 적색 원·사각형이 보이는 경우(해당 팩 수)로 개소당 0.1점이다.
