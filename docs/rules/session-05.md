## 공통 1과제 · 연동 장치 제작

### 장치와 기구 치수

| 항목 | 원본 기준 |
| --- | --- |
| 제어판 | 알루미늄판 **760×600×2 mm**. 로봇테이블 우측 하단에 고정. 찬넬 35×500 mm 1개, 35×575 mm 2개, 와이어링 덕트 40×40×600 mm 6개 |
| 조작판 | 도면 외곽 **375×270 mm**, HMI 개구 228.5×158.5 mm. 표시등·스위치 홀은 지름 25 mm. 위치는 원본 조작판 치수도 기준 |
| 전원·보호 | MCB 220 V·6 A·2P, **FS1 5 A, FS2 3 A**, SMPS DC 24 V |
| 제어·단자대 | PLC 입력 16점, 출력 16점 이상. 위치결정 모듈 POS, 모터 출력카드 TR, 겐트리용 서보드라이버, 릴레이·타이머 릴레이, TB와 서보 인터페이스 단자대 |
| 조작판 기호 | WL1·WL2 백색, RL 적색, GL 녹색, YL 황색. PB0 적색, PB1 녹색. SS는 자동·수동 2단, BZ는 부저, EMS는 비상 스위치 |
| 컨베이어 | S1·S2는 DC 24 V 광센서, 간격 **180 mm**. 시험 팩은 소형 사각 20×20×40 mm |

전원 공급과 컨베이어 제어 회로는 기종에 따라 도면이 달라질 수 있다. 과제지의 로봇 디지털 IO 회로는 참고 도면이다. 지급품 개수 안에서 필요한 릴레이 소켓과 타이머 릴레이 소켓을 사용한다.

### 동작검사

| 입력·조건 | 확인할 출력과 동작 |
| --- | --- |
| MCB 켬 | SMPS 전원 공급, WL1 점등, PLC 전원 차단 상태 |
| SS 자동(A), PB1 누름 | PLC 전원과 WL2가 함께 켜짐. 다시 누르면 둘 다 꺼짐. 자동 중 RL 소등 |
| SS 수동(M) | RL 계속 점등, PLC 전원 차단, WL2 소등 |
| 수동에서 S1이 팩 감지 | t1 뒤 정회전·GL 점등. 도착 센서 S2가 팩을 감지하면 t2 뒤 정지·GL 소등 |
| 수동에서 S2가 팩 감지 | t1 뒤 역회전·YL 점등. 도착 센서 S1이 팩을 감지하면 t2 뒤 정지·YL 소등 |
| 컨베이어 운전 중 PB0 누름 | 즉시 정지, GL·YL 소등. SS가 수동이면 RL 점등 유지 |

- 팩은 출발 센서 중심 근처에 놓는다. **t1은 약 1~3초**, t1을 제외한 타이머 설정은 모두 **1초 이내**다. 타이머는 출발·도착 감지 이후의 지연에만 쓰며 센서 사이 전체 운전 시간을 타이머로 지정할 수 없다. 평가 중 심사위원이 팩을 잡아서 도착 감지를 늦출 수 있다.
- 정·역회전 모두 팩이 도착 센서를 벗어난 뒤 **센서 끝에서 90 mm 이내**에 정지해야 한다. 선수는 평가 직전에 타이머를 조정하고 확인한다. 같은 입력에서 릴레이의 반응 속도에 따라 동작이 달라지는 경우 해당 동작 점수를 받을 수 없다.

### 제작과 배선

- 지정된 위치에 기기를 고정하고 찬넬의 지정 위치에는 스톱퍼를 사용한다. 조작판 기기 아래에 기호 견출지를 붙인다. SS 견출지는 **수동 11시, 자동 1시**에 둔다. 조작판 전선은 케이블 타이 **12개 이상**으로 정리한다.
- 조작판과 외부 입출력 기기는 TB를 거쳐 접속한다. PLC·HMI·겐트리·IT·로봇의 통신케이블은 직접 접속할 수 있다. 전선 끝에는 절연 캡을 포함한 압착 단자를 쓰고 동선이 노출되지 않도록 한다. 단자대 커버를 부착한다.
- 제어판 내부 배선은 덕트에 넣고 완료 후 커버를 닫는다. 외부 입출력 전선은 헤리컬 와이어밴드와 케이블 타이로 정리한다. 과제지에서 외부 케이블은 이 배선 정리 조건의 예외로 둘 수 있다. 드릴 작업에는 손 보호 장갑을 착용하고 배선 작업 중에는 전원을 차단한다.
- PLC·HMI 메모리의 프로그램을 삭제하고 시작한다. 퓨즈를 제외한 재료는 경기장 지급품을 사용한다. 전선은 롤 단위로 준비하며 사전 절단·압착은 금지다. 전원 케이블 및 컨베이어·로봇·겐트리·IT·센서에 연결된 전선은 예외다. 견출지·기명판은 미리 적어 올 수 있고 단자대 커버는 길이를 맞춰 절단해 올 수 있다.
- 1과제 시간 안에 2·3과제용 IT·겐트리·통신선을 제작하고 배선을 확인하거나 공압 부품을 설치할 수 있다. 2·3과제용 별도 준비 시간은 없다.

## 부산 2과제 · 3파레트 슬라이드 정렬

### 파레트와 팩

작업대 범위는 **1200×900 mm**다. A3 가로 폼지에는 **3행×3열, 약 120×120 mm**인 격자 3개가 있다. 팩 중심 간격은 약 40 mm다. 각 파레트에 팩 7개와 빈자리 2개가 있어 실물은 총 **21개**다.

| 팩 | 소형 | 중형 | 대형 | 그리퍼 |
| --- | --- | --- | --- | --- |
| 사각 | 1 | 2 | 3·4 | 전기 |
| 원형 | 5 | 6 | 7 | 공압 |

### 초기값, 이동과 목표

- A·B·C의 시작 배치는 같다. A 초기값을 준비한 뒤 HMI **초기값 복사** 버튼으로 B와 C초기값을 입력한다. B·C 초기값은 이 버튼을 통해 입력하고 **C목표값은 별도로** 입력한다. 기본검사는 과제지의 기본 배치, 랜덤검사는 심사위원 제시값을 사용한다.
- 잡은 팩은 **상하좌우 인접 빈칸 한 칸**으로 옮긴다. 대각선 이동과 다른 팩 위를 넘는 이동은 금지다.
- 좌상단부터 행 순서로 A는 **1~7 오름차순**, B는 **7~1 내림차순**이다. 둘 다 마지막 두 칸은 빈자리다. C는 HMI의 C목표값에 맞춘다.
- A·B의 현재 배치와 C초기값 영역의 현재 배치를 실시간으로 갱신한다. C목표값을 유지한다. 기초검사에서도 기본값과 초기값 복사 버튼을 확인한다.

## 부산 3과제 · 측정 후 정렬

### 파레트와 시작 상태

| 구역 | 자리·인쇄 치수 | 시작 상태와 역할 |
| --- | --- | --- |
| A | 3행×3열, 약 120×120 mm. A1~A9는 왼쪽 위부터 행 순서 | 소·중·대 사각 각 2개. X가 A에 있으면 사각 장애물 1개 추가 |
| IT | 8자리, 작업 출구 6시 | 소·중·대 원형 각 2개. X가 IT에 있으면 원형 장애물 1개 추가 |
| B | 3행×3열, 격자 약 120×120 mm, 파란 선이 있는 위쪽 띠 약 15 mm 별도 | 시작 시 빈 운반 파레트. B-1·B-2와 출구에 같은 B를 이동시킴. 위치 표식 외곽은 각각 약 61×31 mm |
| C | 4행×4열, 약 160×160 mm | 시작 시 비어 있고 이송 완료 후 번호팩 12개, X 1개, 빈자리 3개 |

두 부산 폼지는 A3 가로이며 격자 중심 간격은 약 40 mm다. 치수는 원본을 100% 배율로 환산한 참고값이고, 3과제 B의 격자·띠는 삽입 그림의 외곽선 기준이다. 과제지의 작업대 범위는 **1200×900 mm**다. X는 A 또는 IT 한 곳에만 있으며 크기는 소·중·대 중 하나다.

### 측정과 번호 부여

- **공압 그리퍼만** 내려 센서가 켜진 순간의 Z값으로 크기를 판정한다. 한계 Z까지 신호가 없으면 빈자리다. IT는 6시 출구에서 시작해 반시계 방향으로 한 바퀴 순서대로 읽고 각 측정은 같은 출구 위치에서 한다. A는 A1→A9 순으로 읽는다.
- 해당 구역에서 같은 크기가 첫째·둘째로 읽힌 순서에 따라 번호를 준다. A의 소형 1·2, 중형 3·4, 대형 5·6. IT의 소형 7·8, 중형 9·10, 대형 11·12다.
- 같은 크기가 세 번째로 읽힌 팩은 **X**다. 검출 즉시 C초기값·C목표값의 미확정 X를 실물에 따라 사각 또는 원형으로 확정한다. IT·A 번호는 측정 결과가 나올 때마다 HMI에 반영하며 미리 입력할 수 없다.

### B 경유 이송과 C 정렬

1. **원형팩 먼저.** 겐트리를 **B-1**로 보내고 IT의 7~9를 B 첫째 행, 10~12를 둘째 행에 왼쪽부터 놓는다. IT에 X가 있으면 B의 3행 3열에 놓는다. B를 **출구**로 옮겨 모두 C초기값 위치에 내린다.
2. **사각팩 다음.** 겐트리를 **B-2**로 보내고 A의 1~3을 B 첫째 행, 4~6을 둘째 행에 왼쪽부터 놓는다. A에 X가 있으면 B의 3행 3열에 놓는다. B를 **출구**로 옮겨 모두 C초기값 위치에 내린다. 두 이송은 **전기 그리퍼만** 사용하며 거치 위치마다 B의 파란 선을 해당 위치의 파란 선과 맞춘다.
3. **이송을 모두 마친 뒤 C 정렬.** 사각·원형을 모두 **공압 그리퍼**로 옮긴다. 상하좌우 인접 칸으로만 움직이고 다른 팩이나 X를 넘을 수 없다. 잡은 팩의 하단은 소형팩 상단보다 낮게 유지한다. X는 이 단계에서 고정이고 C초기값·C목표값에서 같은 칸이다.
4. HMI는 IT·A의 측정 상태, B의 거치·반출, C초기값 화면의 현재 상태를 실시간 표시한다. C의 목표 배치는 HMI에서 받은 값을 사용한다.

## 부산 2·3과제 검사와 채점

두 과제의 수행 시간은 각각 3시간이다. **기초 → 기본동작 → 랜덤동작** 순서로 채점한다. 기본·랜덤 준비는 각각 5분·7분, 평가는 10분·15분이다. HMI는 **준비 → 주행 → 완료**로 표시하고 시작·종료 부저를 각각 0.5초 울린다. 주행시간에는 두 부저를 포함하고 완료 뒤 정수 초로 표시한다. 자세·속도·조그·장치 리셋 등 기초검사 조건은 [2차시 검사와 채점](session-02.md#검사와-채점)을 참조한다.

| 과제 | 기초 / 기본 / 랜덤 | 기본·랜덤 각각의 동작 채점 |
| --- | --- | --- |
| 부산 2 | 16 / 7 / 7점 | 초기 1, A 1, B 1, C 1.5, 실시간 1.5, 완료·시간 1 |
| 부산 3 | 18 / 8.4 / 8.5점 | 초기 1, IT·A 측정과 번호 1.4, B 경유 이송 1.3, C 정렬 2, 실시간 1.5, 완료·시간 기본 1.2 / 랜덤 1.3 |

- 실시간 표시는 2과제 A·B·C, 3과제 IT·A·C에 각각 0.5점이다. 해당 파레트나 단계가 제대로 완료되어야 부여한다. 완료·시간은 정렬·이송·실시간 표시 등 앞선 동작 항목 일부에서 점수를 받고, 완료 상태와 시간을 올바르게 기록하면 부여한다.
- 3과제는 항목 제목과 동작 확인서에 기재된 점수를 표에 옮겼다. 본문 설명에는 측정 1점, 이송 1점, C 정렬 1.5점, 기본 완료·시간 1점으로 적혀 있다. 원본의 ‘과제 수행 점수 30점’ 표기와 기초·기본·랜덤의 합계 34.9점도 차이가 있다. 실제 배점은 현장 확정 채점표에서 확인한다.
- 2과제는 기본·랜덤 합계 7점 이상일 때 시간 기본점수 4.9점을 적용한다. 3과제는 과제 수행 점수에서 감점을 적용한다. 시간 순위는 두 주행시간의 합으로 최대 0.1점이다. 대상은 2과제 합계 14점, 3과제 합계 16.9점이다.
- 실행 후 HMI 초기값 수정으로 재평가(최대 2회), 시작 또는 종료 부저 누락(최대 1회), 배치 후 대응하는 적색 정렬 표식이 드러난 경우(해당 팩 수)는 개소당 0.1점 감점이다.
