# 산업용로봇 과제 풀이

공통 1과제와 부산·광주·대구·충남·충북의 2·3과제를 다룬다. 1과제는 회로의 동작 논리를 시간순으로 검증했다. 2·3과제는 과제지 기본동작검사 그림을 입력해 이동 순서를 계산했고, 각 순서를 모델의 초기 상태에 재적용해 목표 배치와 일치하는지 확인했다.

## 실행

저장소 루트에서 Python 3로 실행한다. 외부 패키지는 필요 없다.

```bash
python -m robot all
python -m robot busan2
python -m robot chungbuk3
```

| 실행 이름 | 풀이 | 기본 배치에서 구한 이동 수 |
| --- | --- | --- |
| `common1` | 공통 1과제 전원·컨베이어 | 입력 시점 20개 검증 |
| `busan2` | 부산 3파레트 슬라이드 | A 18, B 16, C 15 |
| `busan3` | 부산 측정 후 정렬 | 17자리 측정, B 경유 적재·하차 26회, C 34 |
| `gwangju2` | 광주 대형 사각팩 이동 | A 60, B 90, C 29 |
| `daegu2` | 대구 밑줄 정렬 | A 39, B 49, C 121 |
| `chungnam3` | 충남 블록 분류 | A 46, B 13, C 58. 각 이동에 앞서 IT 표시 |
| `chungbuk3` | 충북 다리 이동 | A 14, IT 8, B 108, C 29 |

부산 2과제의 이동 수는 단위 이동 비용에서 최소다. 다른 숫자는 탐색이 찾은 경로의 길이다. 부저, 그리퍼 방향 전환, 겐트리·인덱스 이동 및 실제 주행시간은 별도로 다룬다.

### 랜덤 배치 입력

```bash
python -m robot busan2 --input /path/to/layout.json
```

- 부산 2과제는 `{"initial":[6,0,7,1,0,3,5,4,2],"C_target":[1,4,3,0,7,2,6,0,5]}` 형식이다. A·B·C의 초기값은 하나를 공유한다.
- 부산 3과제는 `square_sizes`(A1~A9), `round_sizes`(IT 출구에서 실제로 읽는 순서), `initial`과 `target`(C) 네 배열을 입력한다. 측정값은 0=빈자리, 1=소, 2=중, 3=대다. C는 좌상단부터 행 순으로 16개 값을 넣고 X는 `-1`로 입력한다.
- 광주·대구·충남·충북은 `{"A":{"initial": …,"target": …},"B": …,"C": …}` 형태로 해당 구역의 배치를 바꿀 수 있다. 생략한 구역과 값은 기본 배치를 쓴다. 과제지에 고정된 충북 A·B 목표는 프로그램이 사용한다. [기본 배치와 입력 형식 예시](../robot/examples.py)
- 한 층 격자는 출력 폼지의 유효 자리만 행 순서로 적으며 빈칸은 0이다. 적층은 각 칸을 아래→위 배열로 적고 비어 있으면 `[]`다. 눕힌 팩을 포함한 광주·대구 A·B는 팩 ID를 키로, `[층,[행,열],[행,열]]`을 값으로 입력한다. 한 칸짜리는 끝 좌표를 생략하고 밑줄이 있는 팩은 두 끝의 순서로 방향을 표시한다. 이 입력의 행·열은 0부터 시작한다.
- 충남 B의 배열 순서는 A·B·C·1·2·3·4이고 각 항목은 `[층,왼쪽 끝의 반 칸 인덱스]`다. 충북 B는 각 2×2 구역의 좌상·우상·좌하·우하를 왼쪽 구역부터 이어 붙인 16개 값이다.
- 탐색 한도를 넘으면 오류를 반환한다. 이 경우 풀 수 있는 경로가 있는지는 판정되지 않는다.

## 공통 1과제 · 연동 장치

| 입력·조건 | 상태 전이와 출력 |
| --- | --- |
| MCB ON | SMPS와 WL1 ON. PLC는 OFF 상태로 시작 |
| SS 자동, PB1 새 누름 | PLC와 WL2를 함께 토글. RL OFF |
| SS 수동 | PLC와 WL2 OFF, RL ON |
| 수동에서 S1 감지 | t1 후 정회전, GL ON. S2 감지 후 t2가 지나면 정지 |
| 수동에서 S2 감지 | t1 후 역회전, YL ON. S1 감지 후 t2가 지나면 정지 |
| 운전 중 PB0 누름 | 즉시 정지. GL·YL OFF, 수동 모드의 RL은 ON |

시뮬레이션은 t1=2초, t2=0.5초로 잡았다. 목적 센서 입력을 21초까지 미뤄도 정회전을 유지하고, 21.5초에 정지하는 것을 검증했다. 역회전과 PB0도 확인했다. t1은 1~3초, t2는 1초 이내로 두고 도착 센서 감지를 기준으로 정지 시간을 잰다. 실기 기구 조건의 센서 간격 180 mm와 정지 위치 90 mm 이내는 실물에서 확인한다. FS1 5 A, FS2 3 A와 제어판·조작판 배치는 공통 과제지 도면을 따른다.

## 지역별 풀이의 핵심

- **부산 2**는 팩과 인접 빈칸을 교환하고, 현재 칸에서 목표 칸까지의 거리 합으로 탐색 순서를 정한다. 사각 1~4는 전기, 원형 5~7은 공압이다.
- **부산 3**은 공압 측정으로 번호와 X를 확정하고, 전기 그리퍼로 IT→B-1→C 및 A→B-2→C 순서로 옮긴다. B의 1~6번 칸에 정상 팩을 번호순으로, X는 9번 칸에 둔다. C 정렬 때는 공압을 사용하며 X를 검색 그래프에서 막는다.
- **광주 2**는 A의 눕힌 팩 아래 두 개를 함께 확인한다. B의 중앙은 대형 사각 위에만 소형팩을 둘 수 있고, 위가 비어 있는 대형 사각만 방향을 유지해 이동한다. C는 2층과 1층을 구분하고 사각·원형 층간 교환을 허용한다.
- **대구 2**는 눕힌 팩의 두 끝과 순서를 상태로 저장한다. A는 공압, B·C는 전기를 사용한다. C의 X와 적층된 팩을 건너뛰는 이동을 생성하지 않는다.
- **충남 3**은 A의 표식 4종을 목적 구역에 맞춰 분류하고, B의 겐트리 거치와 C의 두 층을 각각 추적한다. 모든 이동 전 실물 모양과 같은 표식 팩을 IT 출구에 놓는다. C의 H는 직선 통과만 허용한다.
- **충북 3**은 A의 위층을 먼저 정리해 A 목표를 만든 뒤 IT로 적재한다. B는 이동 경로의 초록 칸 점유 여부를 겐트리 위치와 함께 검증한다. C의 다리 이동에는 같은 높이이고 서로 연결된 팩 두 개 이상이 포함된다.

## 모델의 가정과 실기 확인

- 대구 A는 기본 그림에서 소형 6이 이동하지만 본문에서 중형 1~4만 별도로 설명한다. 이 풀이에서는 소형 6도 파란 선을 따라 한 칸 이동하는 것으로 해석했다. A·B 밑줄 방향은 인접 칸을 축으로 90° 회전하는 논리 동작으로 모델링했다. 실기에서는 과제지 그림의 방향별 허용 동작과 회전 중 간섭을 확인해야 한다.
- 광주 A의 대형 사각은 같은 방향의 지지팩 한 쌍으로 옮긴다. 광주 C의 일반 이동은 같은 층에서 하고, 같은 칸의 서로 다른 모양은 층간 교환으로 처리한다. 대형팩의 그립 자세와 층간 교환의 실기 동작은 장비에서 확인해야 한다.
- 충남 B는 기본도에서 긴 팩이 두 칸을 차지하고 상층에서 받침의 이음새를 걸치는 배치를 반 칸 단위로 모델링했다. 실제 받침 높이와 겐트리 기준점, C의 상단 높이와 Z 이동은 장비에서 확인해야 한다.
- 충북 B 시작 겐트리 위치는 좌측 끝으로 설정했다. C는 본문에 다른 번호 범위가 있어 종류표와 기본 HMI 그림이 일치하는 10개(원형 1~5, 사각 6~10)를 사용했다.
- 검증 범위는 논리 배치, 고정 장애물, 이동 순서와 공통 1과제의 이벤트 동작이다. 로봇·PLC·HMI 실기 실행, 충돌 여유, 타이머·센서 실측, 경기 시간 충족 여부는 검증하지 않았다.

## 기본동작검사 이동 순서
